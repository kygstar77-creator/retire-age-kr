
## xv1 — X-V1 영국 실수령 계산기 (영어, 전 세계) — 경쟁 1등 thesalarycalculator.co.uk

심사위원으로서 냉정하게 평가합니다. '우리 v2'는 1등 경쟁사보다는 확실히 모던하지만, 토스 수준의 '금융 프로덕트'로 보기에는 아직 레이아웃의 밀도와 시각적 위계가 부족합니다.

**점수: 6.5**

**[점수를 깎은 이유 3개]**

1.  **시각적 위계(Hierarchy) 혼선:** 최상단 'Your salary' 입력창보다 아래쪽 검은색 'Example' 카드가 시각적으로 더 강하게 튑니다. 사용자가 값을 입력하기도 전에 예시 결과값부터 크게 보여주는 것은 사용자 흐름을 방해하며, 토스라면 입력창 자체를 훨씬 직관적이고 거대하게 배치했을 것입니다.
2.  **불필요한 카드 구분과 여백:** 'Your salary' 카드와 아래 'Student loan...' 아코디언 메뉴 사이의 간격, 그리고 각 요소에 적용된 미세한 그림자들이 화면을 파편화시킵니다. 전체적으로 요소들이 둥둥 떠 있는 느낌을 주어 단단한 완성도가 떨어집니다.
3.  **하단 텍스트의 방치:** 맨 아래 'Estimate only...'로 시작하는 긴 설명 문구는 디자인이 전혀 고려되지 않은 '웹사이트 하단 공지' 수준입니다. 토스나 뱅크샐러드였다면 이 내용을 별도의 정보 아이콘(i)이나 깔끔한 불렛 포인트로 정리해 가독성을 높였을 것입니다.

**[7점 넘게 올릴 고칠 점 3개]**

1.  **입력부와 결과창의 통합 (Merge):** 'Your salary' 입력 칸을 지금보다 1.5배 키우고, 입력 즉시 아래 검은색 카드의 'Example' 태그가 사라지며 실시간으로 결과가 변하게 만드세요. '예시(Example)'라는 중간 단계를 삭제하고 사용자의 행동에 즉각 반응하는 'Live 계산기' 느낌을 주어야 합니다.
2.  **아코디언 디자인 간소화 (Simplify):** 'Student loan'과 'How it's calculated'의 배경색과 테두리를 제거하고, 단순한 구분선(Divider)이나 텍스트 버튼 형태로 바꾸세요. 지금은 메인 기능인 계산기보다 설정 메뉴가 더 무겁게 느껴집니다.
3.  **푸터(Footer) 정보 재배치 (Clean-up):** 하단의 장황한 설명글을 과감히 줄이세요. 꼭 필요한 경고 문구는 1~2줄로 요약해 회색 톤으로 가볍게 처리하고, 상세 설명은 'How it's calculated' 아코디언 내부나 별도 페이지로 격리하여 메인 화면의 정보 밀도를 낮춰야 합니다.
