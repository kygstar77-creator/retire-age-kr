Privacy

No cookies, no local storage. Your exact salary is worked out in your browser and is never sent anywhere.

What we log

To count how the calculators are used, the page sends anonymous events. Each event can include:

  • the event name, such as opening the page, checking a result or tapping Share
  • the salary band checked, such as £50k–£100k (never the exact figure)
  • the page address, the site you came from (for example a search engine) and any campaign tag in the link
  • your screen width
  • a random ID made when the page opens. It isn't saved on your device, so it changes every time you load a page.

These events are stored with Supabase, our database provider. We don't sell them or use them for advertising, and there are no adverts or tracking pixels on this site.

Hosting

This site is hosted on GitHub Pages. GitHub may log visitors' IP addresses for security, as described in the GitHub Pages documentation.

Sharing a result

The Share button makes an image on your device. It shows your salary band, not your exact salary, and goes only where you choose to send it.
