## 왜
- 국세청이 먼저 돌려준 이유: 기본공제를 몰랐거나 착오로 빠뜨린 사례가 많은데 경정청구 건수가 적어서(S1 본문) → c01에 '신고를 다시 살펴본 결과'로
- 250만원을 그대로 돌려주지 않는 이유: 공제는 과세표준을 계산할 때 빼는 금액이라서(S1 문답 5, S2) → c02
- 남은 공제가 다음 해로 안 넘어가는 이유: 법이 '해당 과세기간의 양도소득금액에서' 공제한다고만 함(S2), 이월 규정 없음 → 글엔 이유 대신 사실만

## 그래서
- 홈택스·손택스 '환급금 상세조회'에서 이번 환급(세목 양도소득세·환급결정 2026년 10월) 확인, 계좌 없으면 지급신청 또는 우체국(S1)
- 이번 환급이 없는데 공제를 빠뜨렸으면 신고기한 뒤 5년 안 경정청구(S7) — 2021년 판 주식은 2027년 5월 말까지
- 국세청 사칭 문자에 계좌 비밀번호·카드번호 주지 않기(S1)

## 누구라면
- 해외주식 일반: 22%(20%+지방) → 빠뜨린 250만원으로 55만원 더 냄(S4, calc.py)
- 해외 중소기업 주식: 10% → 27만 5천원(S4 12가)
- 국내 비상장 대주주 1년 미만: 30% → 82만 5천원(S4 11가1), 국세청 예시와 같은 경우
- 이익이 250만원보다 적은 사람: 이익만큼만 공제(S1 문답 10)
- 같은 해 집도 판 사람: 주식 공제 따로 받음(S1 문답 8, S2 각 호별)

## 함정
- 국내·해외주식을 따로 신고하며 250만원을 두 번 넣으면 중복 공제(S1 문답 9)
- '250만원 환급'으로 알고 기다리는 것 — 실제는 세율만큼(S1 문답 5)
- 같은 해 해외주식 손실은 이익에서 먼저 빼야 함(S5) — 빼지 않으면 세금을 더 냄
- 환급을 핑계로 개인정보를 묻는 문자(S1)

## 우리만
- 공제를 빠뜨렸을 때 더 낸 세금을 세율 세 가지로 직접 계산(55만·27만 5천·82만 5천원, calc.py) — 경쟁 6편은 공제를 넣은 계산만
- 2021~2024년에 판 주식의 경정청구 마감 연도(국세기본법 제45조의2 + 소득세법 제110조) — 경쟁 0편
- 국세청 예시를 직접 다시 계산해 맞춤(본세 75만원 같음, 가산금 36,117원 대 보도자료 36,110원 — 일수 계산 끝수 차이) — 글엔 '4만원쯤'

## 예외
- 국내주식 예정신고만 한 사람은 법정신고기한이 반기 예정신고 기준이라 경정청구 마감이 해외주식과 다를 수 있음 → 글의 연도별 기한은 해외주식 확정신고 기준으로만
