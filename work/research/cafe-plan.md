우리 글에는 사람이 없다. 숫자만 있다.

그쪽 카페의 **"금융소득을 조회해 보다가..."는 조회 2,721회**다. 우리 27회짜리와 **같은 주제**인데 100배 차이다.
주제가 문제가 아니라 **누가 왜 쓰느냐**가 다르다.

## 그래서 할 일

### 1. 게시판을 묶음으로 나눈다 (많이가 아니라 길을 내려고)
```
[정보]   미국주식·ETF / 배당·현금흐름 / 부동산 / 세금·연금
[이야기] 질문·고민 / 내 포트폴리오 / 파이어 이야기
[운영]   공지
```
지금 자유게시판 하나에 24편이 쌓여 배당 글 보러 온 사람이 부동산 글 사이에서 헤맨다.

### 2. 회원이 쓸 자리를 먼저 만든다
운영자 정보글만으로는 조회가 안 나온다는 게 숫자로 나왔다(글 89편 게시판 946회 vs 5편 게시판 2,321회).
**질문·고민**과 **내 포트폴리오** 게시판이 그 자리다. 댓글이 생길 유일한 곳이다.

### 3. 정보글에 사람을 넣는다
우리가 쓰는 글은 계속 정보글이다. 다만 "누가 왜 궁금한지"를 첫 줄에 놓는다.
지어내지 않는다 — 우리가 실제로 계산하다 막힌 대목, 자료가 안 맞았던 대목을 쓴다.

### 4. 가입 이유를 만든다
전체공개라 다 읽고 그냥 나간다. **자료 성격이 강한 글(단지표·종목표·계산 결과)만**
멤버공개로 돌린다. 전부는 안 된다 — 검색 유입이 끊긴다.

### 5. 수익화는 등급이 오른 뒤
광고 수익은 **가지 등급부터**(관리 화면 문구). 우리는 씨앗2단계다.
쿠팡파트너스는 멤버 1명한테 붙여야 누를 사람이 없다.

## 확인 못 한 것
- 가지 등급 승급에 필요한 정확한 숫자. 네이버가 공개하지 않는다.
  관리 화면에도 "씨앗2단계"라고만 뜨고 다음 조건이 없다. 네이버 검색으로도 공식 문서가 안 나온다.
- 배당 투자자 모임이 초기에 회원을 어떻게 모았는지. 지금 숫자만 보인다.

## 카페 등급 요건 — 네이버 공식 문서 (2026-09-26 확인)

출처 세 곳, 전부 네이버 공식이다.
- 카페 고객센터 `help.naver.com/service/5622/contents/18597` — 카페 랭킹 및 업데이트 안내
- 카페 고객센터 `help.naver.com/service/5622/contents/15741` — 카페 랭킹 안내
- 카페 랭킹소개 `section.cafe.naver.com/ca-fe/home/ranking-introduction`

### 등급 구조
씨앗 · 새싹 · 잎새 · 가지 · 열매 · 나무 6등급, 각 등급마다 5단계씩 총 30단계.
우리는 지금 씨앗2단계다. 가지1단계는 위에서 세면 11단계 위다.

### 무엇으로 정해지나
활동점수 하나다. 점수가 어느 구간에 들어가느냐로 등급과 단계가 결정된다.
활동점수는 **최근 약 2주간**의 게시글·댓글 작성, 조회, 좋아요, 방문을 반영한다.
단순 활동량뿐 아니라 **멤버 간 상호작용과 참여 방식**도 함께 본다.

### 점수를 올리는 다섯 가지 (공식이 직접 적은 항목)
1. 여러 사람이 게시글과 댓글을 활발히 쓸수록
2. 게시글과 댓글에 좋아요를 누르는 사람이 많을수록
3. 검색을 통해 카페로 들어오는 사람이 많을수록 (글을 네이버에 공개)
4. 새로 가입하는 사람이 많을수록
5. 카페앱을 쓸수록

### 언제 바뀌나
- 활동점수 갱신: 매월 **1일, 16일**
- 실제 랭킹 반영까지: 최대 **7일**
- 한 번에 최대 **2단계**까지 상승 (급등 악용 방지)
- 3회 연속 기준 미달이면 1단계 하락
- 운영원칙 위반으로 경고·이용제한을 받으면 활동점수가 0이 되고 랭킹이 떨어진다

### 씨앗2 → 가지1까지 걸리는 최소 시간
한 번에 2단계, 갱신은 월 2회. 씨앗2(2번째 단계)→가지1(16번째)은 14단계 = 최소 7회 갱신, 가지2(17번째)는 15단계 = 최소 8회 갱신.
(2026-09-27 바로잡음: 처음에 11단계라고 적었는데 30단계 표로 다시 세면 14단계다.)
가장 빠른 길: 10/1 씨앗4 · 10/16 새싹1 · 11/1 새싹3 · 11/16 새싹5 · 12/1 잎새2 · 12/16 잎새4 · 2027/1/1 가지1 · 1/16 가지2~3.
반영 지연 7일을 더하면 빨라야 3개월이다. 이보다 빠를 수는 없다.

### 확인 안 된 것
구간별 점수 컷(몇 점이면 가지1단계인지)은 네이버가 공개하지 않는다.
카페 관리 홈 메뉴를 전부 훑었지만 등급 관련은 '멤버 등급 관리'(우리 카페 안의 회원 등급)뿐이고
카페 자체 랭킹 점수를 보여주는 메뉴는 없다. 공식 안내는 "카페소개 > 랭킹 탭"에서
현재 등급과 활동점수를 볼 수 있다고 한다.

### 그래서 우리가 할 일 (다섯 항목에 그대로 대응)
1·2번이 전부 **멤버 수가 아니라 멤버의 행동**을 본다. 글쓴이 1명·댓글 0개인 지금은
아무리 많이 써도 1번의 "여러 사람"에 걸린다. 발행량을 늘리는 것으로는 등급이 안 오른다.
3번만이 지금 우리가 혼자 할 수 있는 항목이다 — 검색으로 들어오게 하는 것.

### 점수 컷을 찾았다 (2026-09-26)

공개 문서에는 없지만 카페 랭킹 화면이 쓰는 API가 구간을 그대로 준다.
`apis.naver.com/cafe-web/cafe-cafeinfo-api/v1.0/cafes/{cafeId}/ranking?size=7`
(Referer를 랭킹 화면으로 주고 로그인 상태에서 호출)

응답의 `step.prev/current/next`에 각 단계의 `bPoint`~`ePoint`가 들어 있다. 우리 것:

| 단계 | 점수 구간 |
|---|---|
| 씨앗1단계 | 0 ~ 30 |
| **씨앗2단계 (지금)** | **30 ~ 80** |
| 씨앗3단계 | 80 ~ 200 |

**우리 활동점수 63점** (2026-09-01~09-15 구간). 씨앗3단계까지 17점 남았다.

### 점수를 무엇으로 매기는지도 API가 알려준다

`history`에 우리 2주치 실측이 항목별로 들어 있다. 이름이 곧 채점 항목이다.

| 항목 | 우리 값 |
|---|---|
| mobileArticleCount (글) | 20 |
| weeklyArticle | 0 |
| **articleMemberCount (글 쓴 사람 수)** | **1** |
| **commentMemberCount (댓글 쓴 사람 수)** | **0** |
| weeklyComment / mobileCommentCount | 0 / 0 |
| **likeCount / likeMemberCount** | **0 / 0** |
| searchReadCount (검색 유입) | 2 |
| mobileSearchEntranceCount | 1 |
| weeklyMember (새 멤버) | 1 |
| uvMeanCount / uvPoint | 2 / 0 |
| appCafeExecuteCount (앱 구동) | 2 |
| warningCount / paneltyCount | 0 / 0 |

글 20편을 올려서 63점이다. 그런데 **사람 수 항목이 전부 0 또는 1**이다.
채점표에 글 수와 사람 수가 따로 있다는 게 이걸로 확인됐다. 글만 늘려서는 한계가 있다.

이 API는 카페 ID만 바꾸면 남의 카페도 조회된다 → 가지 등급 카페를 조회하면 가지 구간 컷을 실측할 수 있다.

### 30단계 전체 구간표 — 실측 (2026-09-26)

재테크·부동산·주식·절약·은퇴·배당·연금·청약·ETF·가계부·경매·창업 12개 주제로 카페를 모아
각 카페의 랭킹 API를 호출했다. 응답이 prev/current/next 세 단계를 주므로 등급이 다양한
카페를 훑으면 30단계가 전부 채워진다. 구멍 없이 30개 다 나왔다. `work/research/cafe_bands.json`

| 등급 | 단계 | 구간 |
|---|---|---|
| 씨앗 | 1 | 0 ~ 30 |
| 씨앗 | **2 (우리, 63점)** | **30 ~ 80** |
| 씨앗 | 3 | 80 ~ 200 |
| 씨앗 | 4 | 200 ~ 350 |
| 씨앗 | 5 | 350 ~ 550 |
| 새싹 | 1~5 | 550 / 800 / 1,100 / 1,400 / 1,700 ~ 2,000 |
| 잎새 | 1~5 | 2,000 / 2,400 / 2,800 / 3,200 / 3,600 ~ 4,000 |
| **가지** | **1** | **4,000 ~ 5,000** ← 광고 수익 신청 가능 |
| 가지 | 2~5 | 5,000 / 7,000 / 10,000 / 20,000 ~ 30,000 |
| 열매 | 1~5 | 30,000 / 45,000 / 60,000 / 75,000 / 90,000 ~ 110,000 |
| 나무 | 1~5 | 110,000 / 130,000 / 160,000 / 210,000 ~ 300,000 |
| 숲 | — | 300,000 ~ |

**가지1단계 = 활동점수 4,000점.** 우리는 63점이다. 63배다.

비교: 배당 투자자 모임은 숲(332,158점). 월급쟁이부자들·커피작업실·시크릿고수클럽이 나무2단계,
짠돌이카페·대구 부동산 투자가 나무4단계다.

### 이 숫자가 말하는 것
씨앗 구간은 30점씩 끊기는데 가지부터는 1,000점씩 끊긴다. 초반은 쉽고 뒤로 갈수록 가파르다.
잎새5단계(3,600)까지 오는 동안 쌓아야 할 점수가 가지1단계(4,000) 하나와 비슷하다.
한 번에 2단계씩, 월 2회 갱신이므로 씨앗2 → 가지1은 11단계 = 최소 6회 = 약 3개월.
하지만 시간보다 점수가 먼저 걸린다. 3개월 안에 63점을 4,000점으로 만들어야 한다.

## 그 점수를 받으려면 얼마나 해야 하나 — 카페 1,552곳 실측 (2026-09-26)

사장님: "저 점수는 멤버가 얼마여야 하고 글 댓글이 얼마여야 하고 그런 걸 찾아야지"

랭킹 API가 카페마다 2주치 활동을 항목별로 준다. 주제어 150여 개로 카페를 모아
점수 구간별로 묶었다. 도구 `work/cafebench.py`, 자료 `work/research/cafebench.jsonl`.

등급(step)이 아니라 **지금 쌓고 있는 점수**로 묶었다. 카페가 달고 있는 등급은 지난 갱신 때
정해진 것이라 현재 점수와 어긋난다. "4,000점을 받으려면"을 물을 때 맞는 기준은 점수 쪽이다.

2주 한 구간 중앙값 (혼자 찍는 카페 12곳 제외)

|---|---|---|---|---|---|---|---|---|
| **우리** | **63** | **1** | **1** | **20** | **1** | **0** | **0** | **0** |
