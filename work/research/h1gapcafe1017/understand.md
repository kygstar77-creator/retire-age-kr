# h1gapcafe1017 이해 시험 (58세·경제 지식 없음, 새 심사관 Agent 3회)
## 1차 (옛 본문·표지)
- 심각 3: ① c00 '보증금을 그대로 두고'가 보증금이 남는다는 말로 읽힘 → '돌려받아 집값에 보태고'로 ② 표지 '19억'이 사면인지 전세인지 모호 ③ c02 '남아요'와 '더 내요'가 섞임 → 사지 않고 전세로만 옮기는 경우로 따로 소제목, 문장 끝 바꿈
- 약한 것: '쇼츠' '가운데 값' '지금 사는 곳' → 영상·쇼츠 풀이, 가운데 값은 매매가의 가운데라고 씀
## 2차 (고친 뒤)
- 제목: 고덕동에서 전세 보증금을 빼서 헬리오시티를 사려면 돈이 얼마나 모자라느냐 — 맞게 이해(제목 점수 6·8)
- 표지 '헬리오시티 사려면 19억 더'가 집값 19억으로 읽힘(심각 1) → 표지를 '보증금 9억 5천 돌려받고 / 헬리오시티 사면 19억 더 / 전세로 옮기면 3억 더'로 바꿈
- 약한 것: 래미안 항목이 '사는 집을 사는 경우'인지 → 항목에 풀어 씀 · '가운데 값'이 평균인지 → 평균이 아니라 한가운데라고 씀 · '영상에서 말한 값' → 쇼츠에 나온 값 · 오래된 단지거든요 → 값이 낮은 편이라고 이유를 씀
- 표지 고친 판은 새로 읽히는 시험을 못 돌렸고 Gemini 표지 심사(7.5·8)로 대신함
판정: 통과
