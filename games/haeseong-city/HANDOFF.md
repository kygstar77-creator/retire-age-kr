# 해성시티: 인계 메모

클라우드 세션에서 만든 브라우저 3D 오픈월드 게임을 노트북 로컬 세션으로 넘기기 위한 메모입니다.
3D 화면 확인, 그래픽카드 사용, 큰 자료 받기는 클라우드에서 할 수 없어서 로컬로 옮깁니다.

## 위치

- 저장소: `kygstar77-creator/retire-age-kr`
- 브랜치: `claude/gallant-albattani-vltmtp` (main에는 아무것도 넣지 않았습니다)
- 게임 파일: `games/haeseong-city/haeseong-city.html`
- 이 메모: `games/haeseong-city/HANDOFF.md`
- 같은 게임이 claude.ai 비공개 아티팩트로도 올라가 있습니다: https://claude.ai/artifact/EBbihgHtzXS5keWj2Y4tGV

**주의:** retire-age-kr는 은퇴 콘텐츠 프로젝트라 게임이 들어갈 자리가 아닙니다. 사용자는 게임용 새 저장소를 따로 만들고 싶어 합니다.
새 저장소가 생기면 이 폴더를 그쪽으로 옮기고, 이 브랜치의 게임 파일은 지우면 됩니다.
GitHub Free로 공개·비공개 저장소 모두 무료입니다. GitHub Pages로 바로 플레이하게 하려면 공개 저장소여야 합니다.

## 목표 (사용자 요청)

- GTA처럼 현실 세계 같은 오픈월드 게임
- 그래픽을 현실과 최대한 비슷하게
- 직업, 음식, 제작 등 현실 생활 요소를 최대한 많이

## 지금까지 한 것 (버전 1, 웹)

- 기술: HTML 파일 하나 + three.js r128 (cdnjs에서 불러옴, MIT 라이선스). 빌드 과정 없이 브라우저로 열면 실행됩니다. 인터넷 연결은 필요합니다.
- 도시: 가상 해안 도시, 8×8 블록(블록 60m, 도로 14m). 남쪽 바다·해변, 북쪽 산. 시드 고정 난수로 매번 같은 도시가 생성됩니다.
  3D 모델이나 지도 데이터를 외부에서 가져오지 않았고, 건물·차·사람 모두 코드로 만든 상자 모양입니다.
- 들어간 기능:
  - 걷기·달리기·점프, 3인칭·1인칭 전환
  - 차 5종을 아무 차나 타기(드리프트, 충돌)
  - AI 교통 24대(우측통행, 신호등, 교차로 회전), 보행자 약 56명
  - 밤낮 순환(하루 약 8분), 배달·레이스 미션, 숨은 별 12개
  - 미니맵, 속도계, 휴대폰 터치 조작
  - 돈과 별은 브라우저 localStorage에 저장
- 테스트: 헤드리스 Chromium(소프트웨어 렌더링)에서 스크립트 오류 없음. 걷기 → 차 타기 → 운전(3초에 시속 72km) → 벽 충돌이 정상 동작했고, 2분 시뮬레이션 동안 AI 차가 막혀 서 있는 문제 없음.
  **실제 그래픽카드에서의 프레임 속도는 확인하지 못했습니다.** 한 프레임에 그리는 횟수(draw call)는 350~670회입니다.
- 사용자 반응: "그래픽이 너무 별로"라서 실사급으로 바꾸고 싶어 합니다.

## 다음에 할 일

1. **엔진 결정 (사용자와 함께, 확인 없이 진행 금지).** 사용자는 확인 없이 만드는 것을 싫어합니다. 먼저 물어보세요.
   - **Unreal Engine 5:** 실사에 가장 가깝습니다. 무료이고, 게임 하나의 총매출이 100만 달러를 넘으면 넘는 부분의 5%를 냅니다.
   - **웹(three.js) 개선:** glTF 실사 모델, PBR 재질, HDRI 조명, 후처리 효과를 넣고 OpenStreetMap으로 실제 도시를 재현하는 방법입니다.
2. 생활 시스템 단계:
   - 1단계: 배고픔·피로, 집, 돈
   - 2단계: 직업(배달·택시·요리사·편의점)
   - 3단계: 음식(사 먹기, 요리)
   - 4단계: 제작
   - 5단계: 확장
3. 가상 도시로 갈지, 실제 한국 도시를 재현할지 사용자에게 물어보기.

## 노트북 사양 (총무방에서 전달받음)

- 메모리 16GB, 그래픽카드 RTX 3060, C 드라이브 여유 약 106GB
- 판단:
  - Unreal 5는 돌아가지만 권장(메모리 32GB)보다 낮아서 큰 맵에서는 느릴 수 있습니다.
  - 노트북용 RTX 3060은 그래픽 메모리가 6GB라서, 실사 소재를 많이 쓰면 부족할 수 있습니다. 데스크톱용(12GB)인지 확인이 필요합니다.
  - 남은 공간 106GB로는 엔진과 큰 예제 프로젝트를 함께 받기 어렵습니다.

## 받아야 할 큰 자료 (예상 크기, 받기 전에 반드시 사용자에게 크기부터 알릴 것)

| 자료 | 예상 크기 | 비고 |
|---|---|---|
| Unreal Engine 5 (Epic Games Launcher) | 약 40~60GB | 설치 옵션에 따라 다름 |
| Unreal "City Sample" 예제 도시 | 약 100GB 이상 | 남은 공간으로는 사실상 불가능 |
| Fab / Megascans 실사 소재 | 소재 하나에 수십 MB~수 GB | 무료 조건은 각 자료 라이선스 확인 필요 |
| 웹 버전용 glTF 모델·HDRI·텍스처 | 수 MB~수백 MB | Poly Haven 등 무료 출처 |
| OpenStreetMap 도시 데이터 | 구 하나 수 MB, 도시 전체 수백 MB | ODbL 라이선스, 게임 안에 출처 표기 필요 |

위 크기는 대략적인 추정입니다. 실제 크기는 받기 직전에 런처나 사이트에서 확인한 뒤 사용자에게 먼저 알리세요.

## 필요한 API 키 (값은 적지 않음)

- 지금 버전 1은 API 키가 필요 없습니다.
- 앞으로 고르는 방법에 따라 필요할 수 있는 키:
  - 실제 도시를 실사 3D로 불러오는 경우: Google Maps Platform API 키(Photorealistic 3D Tiles) 또는 Cesium ion 토큰
  - OpenStreetMap: Overpass API로 받는 경우 키는 필요 없습니다(대신 사용량 제한이 있음).
  - Unreal Engine과 Fab: Epic Games 계정 로그인이 필요합니다(API 키 아님).
