# 파이어맵 2.0 화면/문구/하드코딩 QA 체크리스트

이 문서는 파이어맵 2.0에서 개발자가 임시로 넣은 값, 쓸데없는 디자인 요소, 사용자에게 어색한 문구가 운영 화면에 남지 않도록 검수하기 위한 기준입니다.

## 1. 하드코딩 검수

화면에 보이는 값이 아래처럼 고정되어 있으면 반드시 의심합니다.

- 특정 나이, 금액, 결과가 사용자 입력과 무관하게 고정되어 있음
- 도시 생활비가 출처 없이 고정되어 있음
- 그래프 값이 실제 시뮬레이션 결과가 아니라 예시값으로 고정되어 있음
- 공유 이미지의 결과값이 실제 입력값과 다름
- AdSense publisher ID, 문의 메일, 정책 URL이 코드 곳곳에 중복으로 흩어져 있음

허용되는 하드코딩:

- MVP 기본 입력값
- 프리셋 금액
- 공식적으로 확정된 문의 메일: retireage.kr@gmail.com
- 서비스 URL: https://retire-age-kr.pages.dev/

원칙:

- 사용자 결과에 영향을 주는 값은 계산 엔진 또는 설정 객체에서 관리합니다.
- 콘텐츠성 값은 추후 데이터/API로 대체 가능하도록 한 곳에 모읍니다.

## 2. 문구 검수

운영 화면에 나오면 안 되는 문구:

- 예정
- 준비 중
- API 연동
- 최신 자료 없으면 숨김
- 개발 중
- 테스트
- 임시
- TODO
- 추후 반영
- mock
- dummy
- hardcoded
- AdSense 영역

사용자용 문구 예시:

- 최신 공식 자료가 확인된 항목만 보여드려요.
- 자료 기준일과 출처를 함께 안내해요.
- 최근 환율 기준으로 계산해요.
- 광고
- 참고용 시뮬레이션입니다.

결과 문구 원칙:

- 너무 확정적으로 말하지 않습니다.
- “가능합니다”보다 “현재 가정으로는”을 우선합니다.
- 세무, 투자, 건강보험 관련 내용은 단정하지 않습니다.

## 3. 디자인 검수

쓸데없는 UI로 판단하는 기준:

- 같은 숫자가 한 화면에 중복 표시됨
- 설명이 길어서 버튼이 아래로 밀림
- 질문 하나에 선택지가 너무 많음
- 결과보다 광고가 먼저 보임
- 초기화 버튼이 너무 쉽게 눌림
- 뒤로가기/결과로 돌아가기 없이 사용자를 막다른 화면에 둠
- 그래프에 축/라벨/범례가 없어 해석할 수 없음

필수 기준:

- 첫 사용자는 30초 안에 앱의 가치를 이해해야 합니다.
- 질문 화면은 한 화면에 하나의 질문만 보여야 합니다.
- 결과 화면은 “그래서 몇 살까지 버티는지”가 가장 먼저 보여야 합니다.
- 조건 바꿔보기에는 반드시 결과로 돌아가기 경로가 있어야 합니다.

## 4. 공유 검수

공유 기능은 단순 텍스트 복사로 끝내지 않습니다.

필수:

- 결과 문구 복사
- 앱 기본 링크 복사
- 내 조건 링크 복사
- 결과 이미지 카드 생성/공유

검수:

- 카카오톡에 붙여넣었을 때 문구가 어색하지 않은가?
- 이미지 카드에 실제 결과값이 들어가는가?
- 공유 링크에 입력값이 포함될 수 있다는 안내가 있는가?
- 너무 긴 URL이 사용자에게 그대로 노출되지 않는가?

## 5. 정책/신뢰 검수

반드시 유지해야 할 문구:

- 입력값은 서버로 전송하지 않고 이 브라우저에 저장됩니다.
- 본 서비스는 투자·세무·법률 자문이 아닌 참고용 계산입니다.
- 내 조건 링크를 공유하면 일부 입력값이 링크에 포함될 수 있습니다.
- 피드백·협업 문의: retireage.kr@gmail.com

AdSense 기준:

- 질문 중간에 광고를 넣지 않습니다.
- 광고 클릭 유도 문구는 금지합니다.
- 광고는 결과 이후 콘텐츠 사이에 자연스럽게 둡니다.

## 6. PM/PMO 검수 질문

기능을 추가하거나 문구를 바꾸기 전 항상 아래 질문에 답합니다.

1. 사용자가 진짜 쓰고 싶어지는가?
2. Toss, 삼쩜삼, 뱅크샐러드, NerdWallet, Credit Karma 같은 앱과 비교했을 때 배울 점이 반영됐는가?
3. 30초 안에 가치가 전달되는가?
4. 공유하고 싶을 만큼 결과가 명확한가?
5. 재방문할 이유가 생기는가?
6. 수익화와 충돌하지 않는가?
7. 개인정보/자산정보 신뢰를 해치지 않는가?
8. 지금 MVP에 필요한가, 아니면 2차 고도화인가?

## 7. main 반영 전 금지 조건

아래 중 하나라도 해당하면 main에 반영하지 않습니다.

- preview에서 빈 화면 발생
- 콘솔 오류로 주요 기능 사용 불가
- 모바일에서 주요 버튼이 가려짐
- 숫자 단위가 합의와 다름
- 결과 공유가 오작동
- 정책/문의 누락
- 개발자용 문구 노출
- 그래프 해석 불가
- 도시 시나리오가 단순 placeholder처럼 보임
