# GPT-6 Astra 웹 사용법 (2026-09-30 사장님: "그냥 웹으로 접속해서 해라, 스꾸 스티커처럼")

- **계정:** 이 PC 크롬에 로그인된 ChatGPT(사장님 Plus 구독)를 쓴다. 모델은 **GPT-6 Astra**.
- **연결 확인:** 2026-09-30 22:5x에 순돌이가 확인했다. 짧은 답도 40초쯤 걸렸다. 추론 강도 기본값이 '최대'이기 때문이다.
- **위험(사장님께 알림 완료, 사장님 결정):**
  - OpenAI 약관은 웹에서 자동으로 결과를 추출하는 것을 금지한다. 계정이 정지될 수 있다.
  - 이 계정은 스꾸 스티커 작업과 같은 계정이다. 사용량을 늘리면 스꾸까지 위험해진다. 그래서 **적게, 꼭 필요한 곳에만** 쓴다.

## 사용 규칙
1. **하루 한도:** 모든 직원을 합쳐 하루 10회 이하. 쓸 때마다 work/research/gpt-usage.jsonl에 한 줄 적는다.
   - 형식: `{"at":"YYYY-MM-DD HH:MM","who":"직원","why":"용도","chars_in":N}`
   - 쓰기 전에 오늘 건수를 세어 보고, 10회면 쓰지 않는다.
2. **스꾸와 섞지 않기**
   - ChatGPT 왼쪽 '프로젝트'에서 **"파이어맵"** 프로젝트 안에서만 새 채팅을 연다. 프로젝트가 없으면 만든다.
   - 스꾸 대화(고정된 스티커·일러스트 요청 등)는 열지도, 읽지도, 지우지도 않는다.
3. **탭**
   - claude-in-chrome에서 `tabs_create_mcp`로 자기 탭을 새로 연다. 끝나면 `tabs_close_mcp`로 닫는다.
   - 다른 회차의 탭은 건드리지 않는다.
4. **넣지 않는 것:** API 키, 비밀번호, 개인정보, 사장님 개인 정보, 스꾸 자료.
5. **답 받기**
   - 보낸 뒤 10초 간격으로 확인한다. '작업 중' 표시가 사라지면 `[data-message-author-role=assistant]`의 innerText를 읽는다.
   - 최대 5분 기다린다. 5분이 넘으면 그 회차에서는 포기하고 기록한다.
6. **결과의 무게:** 반론, 시안, 코드 초안으로만 쓴다. 숫자와 사실은 원문으로 다시 확인한다(no-guessing).
