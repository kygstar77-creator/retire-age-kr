# 퇴사 영수증(참고용) — 화면 설계

- 작성: firemap-designer 2026-10-01 16:39 · 근거: 9/30 23:22 회의 채택(예술가 아이디어 A + 참모 반영표 art/2026-09-30-2318.md 4절) · 기한 spec 10/5, 구현 10/10(product-dev)
- 미리보기: preview.html(시트 375px + 저장 이미지 1080×1350 + 카톡 1200×630) · 경쟁: compare.md
- 정체성: **파이어맵 토큰 그대로**(바탕 #f6f7f9, 글자 #18191d, 주황 #ff5a00, 선 #e5e8eb, Pretendard). 새 부품 1개(영수증 SVG 빌더) — 나머지는 기존 Sheet·Chip·Button·RangeField·ListRow.
- **우리만 다른 한 가지(첫 화면에 보이는 것):** 큰 숫자가 금액이 아니라 **"약 N개월"**이고, 그림이 **금액 숨김 상태로** 공유된다. 영수증 모양 자체는 MyMoneySim이 이미 쓴다(compare.md 1) — 모양을 내세우지 않는다.
- 예시 숫자(preview): 2023-10-01 입사·2026-10-01 퇴직·월 300만원·50세 미만·생활비 월 250만원 → 퇴직금 8,812,388원, 실업급여 1일 66,048원(최저구직급여일액)×180일=11,888,640원, 3.5개월 / +4.7개월. **실제 식으로 계산한 값**(src/utils/severancePay.js·unemploymentBenefit.js, node 16:3x). 생활비 250만원은 예시 가정.

## ① 누가, 어디서
- /calc/severance 결과를 막 본 사람(퇴직금 계산기 검색·카페 글 utm·쇼츠 설명란). 이미 퇴사를 정했거나 고민 중.
- 보낼 곳: 동료 단톡방·퇴사 고민 카페 글. 금액은 보이기 싫어한다(전략 참모) → 기본 숨김.

## ② 처음 30초
1. 퇴직금 결과(기존) → 주황 버튼 '이 돈이면 몇 살에 은퇴?'(그대로, 화면의 행동 1개) → 가정값 1줄 → '다음 계산(실업급여)' ListRow → **새 ListRow '퇴사 영수증(참고용)' + 오른쪽 아이콘(이미지)**. 주황 없음. 쿠팡 칸은 그 아래.
2. 누르면 Sheet가 열린다. 입력은 **0개 또는 1개**:
   - 저장된 파이어 입력(inputsIsReal)이 있으면 한 달 생활비·나이를 거기서 가져와 **바로 그림**.
   - 없으면 RangeField '한 달 생활비' 1개만(빈 칸으로 시작, 넣기 전엔 큰 숫자 자리 '—'). 나이는 칩 '이직일에 50세 이상'(기본 꺼짐).
3. 시트 안 순서(위→아래): 영수증 미리보기(저장될 그림 그대로) → 칩 '금액 보이기'(기본 **꺼짐**) → 주황 Button '이미지 저장'(시트의 행동 1개) → 회색 2칸 '카카오톡 공유'·'링크 복사'.

## 영수증 그림(1080×1350, 기존 buildCertSvg와 같은 길: functions/og-card.js에 buildReceiptSvg)
흰 종이 한 장(가로 840, 위·아래 톱니 가장자리), 바탕 #f6f7f9. 고정폭 숫자(tabular-nums). 좌우 여백 120.
1. 머리: "퇴사 영수증(참고용)" 44px 700 · 아래 줄 28px ink-2 "퇴직일 2026.10.01 · 근속 3년 0개월"
2. 점선 1줄
3. **큰 숫자 블록:** 라벨 30px ink-2 "퇴직금만으로" / 숫자 **"약 3.5개월" 128px 800 주황** / 아래 26px ink-3 "한 달 생활비 250만원 기준"
4. 둘째 줄(조건): "실업급여 받으면 **+4.7개월**" 40px ink(숫자만 700) / 바로 아래 24px ink-3 "수급 자격 충족 시 · 1일 66,048원 × 180일"
   - 금액 숨김이면 1일 금액 자리 '비공개', 일수(180일)는 남긴다(법 별표 1 값이라 개인 정보 아님).
4-1. (저장된 파이어 입력이 있고 calc-3 gainYears ≥ 1일 때만) 24px ink-2 한 줄 "퇴직금을 더하면 파이어 나이가 N년 앞당겨져요" — calc-3 숫자 줄과 **같은 글자·같은 값**(SeveranceCalc gainYears 재사용, 새 말 0). 없으면 줄을 그리지 않는다.
5. 점선 1줄
6. 금액 줄(**'금액 보이기' 켰을 때만**): "퇴직금(세전) 8,812,388원" / "실업급여 총액 11,888,640원". 꺼져 있으면 이 칸을 통째로 빼고 높이를 줄인다(가림 막대 금지 — 가린 티가 공유를 막는다).
7. 바닥 22px ink-3 2줄: "세전·퇴직소득세 별도 · 피보험기간 = 근속기간 가정" / "2026년 기준 · firemap.kr/calc/severance"
- 금지: 정부 로고·'원천징수영수증'과 비슷한 표 머리·바코드(공문서처럼 보임), 캐릭터, "버틴다" 같은 지은 말(글자는 firemap-editor-web 확정 — 지금 문구는 회의 채택안에 있던 말만 씀).
- 개월 수: 금액 ÷ 생활비, **소수 1자리 내림**. 1개월 미만이면 "1개월 미만".
- 실업급여 줄을 **빼는** 경우: 퇴직일이 2026년 밖(계산 파일이 2026만 함, supported:false) · 근속 180일 미만. 이때 둘째 줄 자리를 비우고 위로 당긴다.

## 카톡 미리보기 1200×630(buildReceiptWideSvg)
- 왼쪽 반: 영수증 종이 상단(제목·큰 숫자). 오른쪽 반: "퇴직금만으로 약 3.5개월" / "+ 실업급여 4.7개월(수급 자격 충족 시)". 금액은 숨김이 기본이므로 **카톡 그림엔 금액을 아예 싣지 않는다**(켜도). 링크 query에도 금액을 넣지 않는다 — 개월 수·일수·기준만(`/og?mode=rcpt&m1=3.5&m2=4.7&ud=180&yr=2026`). 금액을 보인 그림은 '이미지 저장'으로만 나간다.

## ③ 경쟁 대비 이길 점 2개 — 어디서 보이나
| 이길 점 | 어디서 |
|---|---|
| 금액 대신 '약 N개월' + 실업급여는 조건 붙은 둘째 줄(경쟁 0곳) | 그림 3·4번, 시트 열자마자 미리보기 맨 위 |
| 받는 사람이 **내 결과 그림**을 본다(MyMoneySim은 빈 계산기 주소만) · 금액 기본 숨김 | 시트 칩 '금액 보이기'(꺼짐), 카톡 그림 |

## ④ 결과 다음 단계
- 영수증 바닥 주소 = /calc/severance(받은 사람이 자기 영수증을 만든다).
- 받은 사람이 /s?mode=rcpt 로 들어오면 첫 화면 = 퇴직금 계산기(빈 입력) + 맨 위 회색 1줄 "친구 영수증: 퇴직금만으로 약 3.5개월"(Notice 기존 부품). 그다음은 기존 주황 버튼 '이 돈이면 몇 살에 은퇴?'로 이어짐.
- 시트 안에 은퇴 버튼을 또 넣지 않는다(행동 1개).

## ⑤ 공유 장치
- '이미지 저장': SVG → Image → canvas 1080×1350 → toBlob(png). 모바일에서 `navigator.canShare({files})`면 share({files}) (iOS는 이게 '사진에 저장'), 아니면 a[download]. **저사양 기기 3초 이내**(전략 참모 확인 2) — product-dev가 갤럭시 A 계열 또는 CPU 6배 느리게(DevTools)로 잰다. 넘으면 SVG 글꼴을 시스템 글꼴로.
- '카카오톡 공유': 기존 shareToKakao, 1200×630 그림.
- '링크 복사': /s?mode=rcpt… 주소.
- 서버 전송·저장 없음. 금액은 브라우저 안에서만 그린다.

## ⑥ 375px 배치(시트)
- 시트 미리보기는 저장 그림 전체(1080×1350)가 아니라 **종이 부분만 잘라**(viewBox를 종이 경계로) 보여 준다 — 전체를 넣으면 343폭에서 둘째 줄 이하가 7px대로 안 읽힌다(preview.png ② 실측). 저장·카톡 그림은 그대로.
- Sheet 안쪽 폭 343. 미리보기 SVG는 폭 100%(343 → 높이 429). 시트 높이가 화면을 넘으면 미리보기만 줄어든다(max-height 52vh, 가로세로비 유지) — 버튼 3개는 375×667에서 스크롤 없이 보이게.
- 생활비 RangeField가 나올 때(저장 입력 없음)는 미리보기 max-height 40vh.
- 320px: 버튼 2칸은 그대로 2칸(기존 ds-bottomcta), 칩 1줄.

| 이벤트 | 언제 | 값 |
