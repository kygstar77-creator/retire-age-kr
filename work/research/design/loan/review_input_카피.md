### ⚠️ 사실과 다르거나 오해될 문구 목록
1. **F 시안:** "10만원"을 제목에 확정적으로 사용. 사용자가 다른 금액을 입력할 경우 제목과 본문 내용 불일치 발생.
2. **K1, K5 버튼:** 현재 v1에서 대출 데이터가 파이어 계산기로 넘어가지 않음에도 불구하고, 대출이 반영된 은퇴 나이를 알려줄 것처럼 묘사함(낚시 위험).
3. **만기일시 상환 시 안내:** "움직이면 다 갚는 나이가 바뀌어요"는 만기일시 상환 방식에서 사실과 다름(만기일시는 원금을 마지막에 갚으므로 매달 더 갚아도 종료일은 동일함).
4. **E-0 결함:** 엔진 결과 "0개월 일찍"이 나올 때 "끝나는 나이는 같아요"로 예외 처리가 되지 않으면 사용자 혼란 야기.
