증여세 세율·증여재산공제 — 확인된 사실표 (확인일 2026-09-22)
출처: 상속세 및 증여세법 (law.go.kr DRF 원문, 시행 2025.10.1 = 2026-09-22 조회 시점 현행)

[제56조] 증여세 = 제55조 과세표준 x 제26조 세율 (상속세와 같은 세율표)
[제26조 세율]
  1억원 이하: 과세표준의 10%
  1억 초과 5억 이하: 1천만원 + 1억 초과분 20%
  5억 초과 10억 이하: 9천만원 + 5억 초과분 30%
  10억 초과 30억 이하: 2억4천만원 + 10억 초과분 40%
  30억 초과: 10억4천만원 + 30억 초과분 50%
[제53조 증여재산 공제] 거주자가 받은 경우, 10년 이내 공제받은 금액 합산해 한도 초과분 공제 안 함
  1. 배우자: 6억원
  2. 직계존속(수증자의 직계존속과 혼인 중인 배우자 포함, 사실혼 제외): 5천만원, 미성년자는 2천만원
  3. 직계비속(수증자와 혼인 중인 배우자의 직계비속 포함): 5천만원
  4. 그 밖의 4촌 이내 혈족, 3촌 이내 인척: 1천만원
[제53조의2 혼인·출산 증여재산 공제] (본조신설 2023.12.31)
  ① 직계존속으로부터 혼인일(혼인관계증명서상 신고일) 전후 2년 이내 증여: 제53조 공제와 별개로 1억원
  ② 자녀 출생일·입양일부터 2년 이내 증여: 별개로 1억원
  ③ 혼인+출산 공제 합계 1억원 한도
  ⑥ 혼인 전 공제 후 2년 내 혼인 안 하면: 2년 되는 달 말일부터 3개월까지 수정신고·기한후신고 시 가산세 전부·일부 면제, 이자상당액 가산
[제47조②] 증여일 전 10년 이내 동일인(증여자가 직계존속이면 그 배우자 포함)에게 받은 증여재산 합계 1천만원 이상이면 합산
[제55조②] 과세표준 50만원 미만이면 증여세 부과 안 함
[제57조① 할증] 수증자가 증여자의 자녀가 아닌 직계비속(손자녀 등): 산출세액 +30%, 미성년자이면서 증여재산가액 20억 초과 +40%. 자녀가 사망해 그 자녀(손자녀)가 받는 경우 제외
[제69조②] 신고기한 내 신고 시 산출세액(할증 포함)의 3% 공제 (신고세액공제)
[제68조①] 신고기한: 증여받은 날이 속하는 달의 말일부터 3개월 이내, 납세지 관할 세무서장
[제70조②] 납부할 금액 1천만원 초과 시 일부를 납부기한 지난 후 2개월 이내 분할납부 가능(연부연납 허가받으면 제외)
[제4조의2①] 납부의무자 = 수증자(받은 사람)
[제46조 5호] 사회통념상 인정되는 이재구호금품, 치료비, 피부양자의 생활비, 교육비 등은 비과세
[제45조④] 실명 확인된 계좌 재산은 명의자가 취득한 것으로 추정

[계산값 — 위 조문으로 직접 계산, 10년 내 다른 증여 없음 가정]
  성인 자녀가 부모에게 1억: 과표 5천만 x10% = 500만, 신고공제 15만 → 485만원
  3억: 과표 2.5억 → 1천만 + 1.5억x20% = 4천만, 공제 120만 → 3,880만원
  5억: 과표 4.5억 → 1천만 + 3.5억x20% = 8천만, 공제 240만 → 7,760만원
  미성년 자녀 5천만: 과표 3천만 x10% = 300만, 공제 9만 → 291만원
  성인 손자녀가 조부모에게 1억: 500만 x1.3 = 650만, 공제 19.5만 → 630.5만원
  혼인신고 전후 2년 내 부모에게 1.5억: 공제 5천+1억 → 과표 0 → 0원
  배우자 6억: 과표 0 → 0원
  9월 22일 증여 → 9월 30일부터 3개월 → 12월 31일까지 신고
확인 안 함(본문에 안 씀): 무신고·과소신고 가산세율(국세기본법), 부동산 증여 시 취득세, 시가 평가 방법 세부

[국세기본법 (law.go.kr DRF, 시행 2026.8.11)]
  제47조의2① 무신고가산세: 무신고납부세액의 20%, 부정행위 40%(역외거래 60%)
  제47조의3① 과소신고가산세: 과소신고납부세액등의 10%, 부정행위분 40%
  제47조의4① 납부지연가산세: 미납세액 x 기간 x 대통령령 이자율 (이자율은 시행령 미확인 → 본문에 숫자 안 씀)
[누진공제액 — 제26조 세율표에서 계산한 값]
  1억 이하 0 / 5억 이하 1천만원 / 10억 이하 6천만원 / 30억 이하 1억6천만원 / 30억 초과 4억6천만원
  (예: 20% 구간 1천만+(과표-1억)x20% = 과표x20%-1천만)
