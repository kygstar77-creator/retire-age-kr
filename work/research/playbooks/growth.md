# 성장·유입 교본 (firemap-growth) — v1 2026-09-30

> 매 회차 시작에 lessons.md 다음으로 읽는다. 끝나면 '배운 것'에 1줄 이상.
> 이 자리는 firemap.kr 방문을 늘린다: ① 채널→사이트 유입 측정(utm) ② 교차 연결 ③ 검색 노출 점검 ④ 유입 실험. 로드맵 목표선: 10월 10만원 ≈ 월 4만 PV, 11월 50만원 ≈ 월 20만 PV(페이지 RPM 2,500원은 '가정'). 사이트 코드는 직접 고치지 않는다(요청은 product-dev에게).

## 1. 이 자리 전문가가 아는 것

1. **잴 수 없으면 키울 수 없다. utm 세 개는 필수.** 구글 애널리틱스: utm_source·utm_medium·utm_campaign은 항상 쓴다. 값은 대소문자를 구분한다(google ≠ Google). 규칙을 한 파일(growth/utm.md)에 두고 모두가 같은 값을 쓴다.
   - 출처: https://support.google.com/analytics/answer/10917952
2. **성장은 주간 비율로 잰다.** 폴 그레이엄: 주 5~7%면 좋고, 10%면 예외적, 1%면 아직 못 찾은 것. 매달 새 사용자 수가 일정하면 성장률은 떨어지고 있는 것이다.
   - 출처: https://www.paulgraham.com/growth.html
3. **링크는 글의 일부여야 한다.** 네이버 공식: 대량 링크, 본문이 링크로 끝나는 '기-승-전-링크'는 문제다. 한 글에 관련 계산기 1개, 모든 글에 같은 링크 반복 금지.
   - 출처: https://blog.naver.com/naver_search/220748087250
4. **영상이 사이트로 보내는 통로로만 쓰이면 스팸이다.** 유튜브 스팸 정책: 외부 사이트로 유도할 목적으로만 만든 콘텐츠 금지. 영상만으로 완결되고, 링크는 더 보고 싶은 사람을 위한 것.
   - 출처: https://support.google.com/youtube/answer/2801973 · https://support.google.com/youtube/answer/9054257
5. **검색 유입의 기본은 고유한 제목·설명·링크 글자.** 페이지마다 고유한 title·description, 링크 글자는 연결된 페이지를 설명. keywords 메타는 쓰이지 않는다.
   - 출처: https://developers.google.com/search/docs/fundamentals/seo-starter-guide
6. **트래픽을 사거나 만들면 광고 계정이 끝난다.** 애드센스: 어떤 방법으로든 클릭·노출을 인위적으로 만들면 엄격히 금지, 클릭 유도도 금지. 자동 클릭·트래픽 교환 금지.
   - 출처: https://support.google.com/adsense/answer/48182
7. **실험은 기간·표본을 먼저 정하고 판정일에만 본다.** 중간에 들여다보고 멈추면 오판율이 크게 오른다(매 관찰 5% 기준이면 26.1%). 한 번에 1~2개, 4주.
   - 출처: https://www.evanmiller.org/how-not-to-run-an-ab-test.html
8. **실험의 대부분은 효과가 없다.** 긍정 결과는 10~20%(구글·빙). 하나의 종합 지표(예: 사이트 방문 → 계산 완료)를 정해 둔다.
   - 출처: https://hbr.org/2017/09/the-surprising-power-of-online-experiments

## 2. 회차 체크리스트

- [ ] 내부 방문(?fm_internal=1, 예약 작업 점검 요청) 제외 확인.
- [ ] 새 링크가 utm.md 규칙대로인지 표본 3개 확인(대소문자까지).
- [ ] 교차 연결 제안: 글·영상 하나에 관련 계산기 1개, 같은 링크 반복 없음. 네이버 무인 발행 글에 쿠팡 링크 없음.
- [ ] 새 계산기가 나오면 그 주제 글·쇼츠를 담당에게 today.md로 요청.
- [ ] 검색 노출: 사이트맵·색인 상태·검색어 순위. 도구가 없으면 연결 방법을 결재함에.
- [ ] 실험: growth/experiments.md에 가설·지표·표본/기간·중단 기준·판정일. 판정은 키우기/유지/접기.
- [ ] 금지 방법이 섞이지 않았는지: 스팸, 다른 카페 홍보글, 오픈채팅·쪽지 링크 뿌리기, 자동 클릭, 사람 손이 드는 방법.
- [ ] 주간 증가율(방문·계산 완료)을 로드맵 목표선과 비교.

## 4. 아마추어 실수 → 전문가 방식

| 실수 | 전문가 방식 |
|---|---|
| 채널→사이트 유입을 재는 사람이 없었음(전략 참모 지적) | utm 규칙 + 매일 한 줄 |
| 카페 방문 1,736명·가입 0(9/22~26) — 방문만 보고 성공이라 봄 | 방문 → 핵심 행동(가입·계산 완료)까지 짝으로 본다 |
| 모든 글에 같은 계산기 링크 | 주제 맞는 1개, 반복 금지 |
| 하루치 숫자로 추세 단정 | 주간 비율로 |
