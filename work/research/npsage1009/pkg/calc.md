# 1964년생 · 정상 수령 시 월 100만원인 사람 기준 계산

작성 2026-10-08 14:31 KST

## 전제
- **명목 금액으로 계산.** 매년 물가에 맞춰 올려 주는 금액(제51조제2항 재평가·물가연동)은 뺐다. 실제로는 모든 경우에 매년 금액이 오르고, 그만큼 금액 차이도 같이 커진다.
- 부양가족연금은 없다고 가정(조기 감액·연기 증액은 부양가족연금에는 안 붙음).
- 일하면서 받을 때 깎이는 금액(제63조의2), 세금, 건강보험료는 반영 안 함.
- 생일 달에 받기 시작해 매달 받는다고 가정. 누적 = 월액 × 12 × (나이 − 개시 나이).
- 1964년생 정상 수령 = **63세(2027년)**. 의뢰서의 "65세(2029년)"는 1969년 이후 출생자 기준이라 바로잡았다(부칙 제8조: 1961~64년생 +3세).

## 역전 나이(누적이 같아지는 나이)
식: m1 × (x − s1) = m2 × (x − s2) → x = (m2·s2 − m1·s1) / (m2 − m1)

| 비교 | 계산 | 역전 나이 |
|---|---|---|
| 58세 조기(70) vs 63세 정상(100) | (100·63 − 70·58)/30 = 2240/30 | **74.67 → 74세 8개월** |
| 60세 조기(82) vs 63세 정상(100) | (6300 − 4920)/18 = 1380/18 | **76.67 → 76세 8개월** |
| 63세 정상(100) vs 68세 연기(136) | (136·68 − 6300)/36 = 2948/36 | **81.89 → 81세 11개월** |
| 58세 조기(70) vs 68세 연기(136) | (9248 − 4060)/66 = 5188/66 | **78.61 → 78세 7개월** |
| 60세 조기(82) vs 68세 연기(136) | (9248 − 4920)/54 = 4328/54 | **80.15 → 80세 2개월** |

뜻: 이 나이보다 오래 살면 늦게 받는 쪽이 누적으로 앞선다. 이 나이 전에 사망하면 일찍 받는 쪽이 앞선다.
