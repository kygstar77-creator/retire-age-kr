# 파이어맵 수익률 시나리오 계획

현재 MVP 계산 엔진은 기본 연 수익률 8%, 물가상승률 3%를 사용한다. 하지만 화면에는 이 가정이 충분히 보이지 않는다.

## 1차 반영

- 결과 화면에 현재 계산 기준 표시
- 문구: 현재 계산 기준 · 연 수익률 8% · 물가 3%
- 조건 바꿔보기 화면에 수익률 조절 추가

## 2차 반영

투자 성향별 프리셋을 추가한다.

- 보수형
- S&P500형
- 나스닥100형
- 미국배당다우존스형
- 직접입력

각 프리셋은 같은 입력값에서 몇 살까지 버티는지 비교한다.

## 데이터 원칙

- 2025~2026년 기준으로 확인 가능한 자료만 사용
- 최신 자료가 없으면 확정값처럼 쓰지 않음
- 소비자 화면에 작은 출처 표시
- 수익률 보장 표현 금지

## 차트 방향

주식창처럼 익숙하게 보이되 목적은 수익률 자랑이 아니라 FIRE 경로 비교다. 1차는 선을 많이 늘리지 않고 카드 선택 또는 토글 방식으로 간다.
