# 블로그가 검색에 안 잡히는 문제 — 원인 추적

## 증상 (2026-09-21 01:40 실측, work/perf.py)
어제(9/20) 발행한 블로그 3편 중 2편은 **제목을 그대로 네이버에 검색해도 안 나온다**.
나머지 1편도 29위. 사장님이 직접 쓴 6월·2월 글은 제목 검색 1위.
같은 날 쓴 카페 글은 "9월 재산세 납기"에서 7위로 정상 노출된다.

| 글 | 발행 | 제목 그대로 검색 |
|---|---|---|
| 2026년 연봉 실수령액이 작년보다 줄어든 이유, 국민연금 9.5% | 9/20 | 29위 |
| 9월 재산세 고지서, 7월에 냈는데 또 나온 이유와 30일 납부기한 | 9/20 | 안 나옴 |
| 청년미래적금 2차 신청기간·대상과 1차 79.6만명 탈락 사유 | 9/20 | 안 나옴 |
| 내 파이어 가능 나이를 계산해보자! 언제 파이어 하려나? | 6/20 | 1위 |
| 코스피의 질주와 나의 침묵, 30대 중반의 투자는 외롭다 | 2/25 | 1위 |

## 확인한 것

### 1. 서치어드바이저 등록 — 불가능. 원인이 아니다. (2026-09-21 02:10 확인)
searchadvisor.naver.com 웹마스터 도구에 `https://blog.naver.com/kygstar7777` 를 넣으니
**"URL을 호스트 단위로 입력해주세요."** 로 거절됐다. 서치어드바이저는 도메인 단위로만
사이트를 받는데 `blog.naver.com` 은 네이버 소유라 우리가 등록할 수 없다.
→ **네이버 블로그는 서치어드바이저 등록 대상이 아니다.** 미등록이 색인 실패의 원인이라는
가설은 틀렸다. 이 줄을 근거로 rules.json의 해당 규칙을 고쳤다.

### 2. 블로그 관리 페이지 주소 (2026-09-21 02:12 확인)
`https://admin.blog.naver.com/<blogId>` 로 열린다.
`/config/wholeView` 를 붙이거나 `?blogId=` 로 넘기면 "페이지 주소를 확인해주세요"가 뜬다.

## 아직 확인 못 한 것 — 다음 점검 회차가 하나씩

- [ ] **블로그 기본 설정의 검색 노출 항목 체크 상태.** 관리 페이지는 열었지만 화면 왼쪽이
      다른 앱 창(계산기·캡처 도구·텔레그램·스티커 메모)에 가려 체크박스를 볼 수 없었다.
      computer-use가 허용 밖 앱 위치를 검게 칠하기 때문이다. 웨일 창을 오른쪽으로 옮기거나
      그 앱들을 닫고 다시 볼 것.
- [ ] **글 단위 발행 설정.** 발행할 때 전체공개·검색허용이 실제로 켜져 있었는지.
      9/20 글 3편을 열어 확인.
- [ ] **유사문서 여부.** 안 나오는 글의 본문 한 문장을 따옴표로 묶어 검색해서, 우리 글 대신
      다른 글이 원본으로 잡히는지 본다. 네이버 유사문서 판독시스템(공식블로그 2018.10.30)은
      블로그·카페 모두에 적용된다.
- [ ] **블로그 통계의 유입 경로.** 한 번도 열지 않았다. 검색 유입이 0인지, 아니면 들어오는데
      순위만 낮은지 갈린다.
- [ ] **색인 지연 가능성.** 9/20 글은 하루밖에 안 지났다. 9/22 이후에 다시 재서 그대로면
      지연이 아니라 걸러진 것이다. perf_log.json에 날짜별로 쌓이고 있으니 비교할 수 있다.

## 하지 말 것
원인을 하나로 단정하지 않는다. 위 항목을 재지 않은 채 "블로그 지수가 낮아서"라고 적는 것은
추측이다. 잰 것만 이 파일에 쓴다.

## 결론 (2026-09-21 11:30) — 색인 문제가 아니었다. 순위 문제다.

본문 한 문장을 따옴표로 묶어 블로그탭에서 검색했다.

| 글 | 제목 그대로 검색 | 본문 문장 검색 |
|---|---|---|
| 재산세 (9/20) | 30위 밖 | **우리 블로그 잡힘** |
| 청년미래적금 (9/20) | 30위 밖 | **우리 블로그 잡힘** |
| 연봉 실수령액 (9/20) | 25위 | **우리 블로그 잡힘** |
| 종부세 (9/21 02:30 발행) | 30위 밖 | **우리 블로그 잡힘** (9시간 만에) |

- 색인됨. 네이버가 글을 알고 있다.
- 유사문서 아님. 다른 블로그가 원본으로 잡히지 않았고, 우리 카페 글과 같은 문장도 없다.
- 제목 검색 순위에만 안 올라온다.

사장님 판단("색인이 안 되지 않을 거야")이 맞았다. perf.py의 "제목 검색에 안 나오면 색인 실패"
판정이 틀린 기준이었고, 그걸 근거로 블로그를 건너뛰게 했던 것도 틀렸다.

**다음에 볼 것은 순위다.** 같은 키워드로 상위 10위 글과 우리 글이 무엇이 다른지. 후보
(아직 재지 않음): 블로그 지수(글 수·기간·방문자), 제목 검색어가 실제 사람들이 치는 말과
다른가, 발행 후 경과 시간. 제목이 길고 고유할수록 제목 검색에 잘 걸린다는 점도
확인해야 한다 — 사장님 옛 글 두 편은 제목이 독특해서 1위일 수 있다.

## 순위 비교 1차 (2026-09-22 12시 점검 회차) — 잰 것만

9/20~21 블로그 6편을 사람들이 실제로 치는 대표 검색어(kwvol 월 검색수)로 블로그탭에서 검색해
상위 10편 본문(m.blog)과 우리 글을 비교했다. 도구: toprank.py의 search·post 함수.

| 검색어 (월 검색수) | 우리 순위(30위까지) | 제목에 검색어: 상위10 / 우리 | 글자수 중앙값: 상위10 / 우리 | 사진 중앙값: 상위10 / 우리 |
|---|---|---|---|---|
| 국제유가 (1,730,900) | 30위 밖 | 10/10 / 들어감 | 4,008 / 2,280 | 6 / 6 |
| 청년미래적금 (397,500) | 30위 밖 | 10/10 / 들어감 | 3,048 / **3,284** | 5 / 6 |
| 재산세 (75,400) | 30위 밖 | 10/10 / 들어감 | 2,888 / 2,063 | 4.5 / 5 |
| 연봉 실수령액 (75,100) | 30위 밖 | 5/10 / 들어감 | 2,411 / 1,796 | 6.5 / 3 |
| 종부세 (22,370) | 30위 밖 | 10/10 / 들어감 | 3,114 / 2,149 | 6 / 6 |
| 삼성전자 실적발표 (2,390) | 30위 밖 | 7/10 / 들어감 | 3,900 / 2,031 | 4.5 / 6 |

- **제목 검색어**: 6편 모두 대표 검색어가 제목에 들어 있다. 차이 아님.
- **글 길이**: 6편 중 5편이 상위 10편 중앙값보다 짧다(700~1,900자 적음). 그러나 청년미래적금은 우리가
  더 긴데도 30위 밖이다 → 길이만으로는 설명되지 않는다.
- **사진 수**: 연봉 실수령액(3장 vs 6.5장)만 적고 나머지는 같거나 많다. 차이 아님.
- **경과 시간**: 상위 10편 날짜 표기는 대부분 1일~3주 전이고, 우리 글은 1~2일 전이다. 우리 글이
  "오래돼서" 밀린 것은 아니다. (날짜 목록은 검색 결과 HTML에서 따로 뽑아 결과 순서와 1:1 대응을
  확인하지 않았다.)
- 제목 그대로 검색하면 삼성전자 1위·국제유가 10위지만, 대표 검색어로는 둘 다 30위 밖이다 —
  제목 검색 순위는 실제 유입 순위가 아니다.

**아직 못 잰 것:** 블로그 단위 신뢰도(글 수·운영 기간·방문자·이웃 수)를 상위 블로그와 비교하지 않았다.
글 요소(제목·사진·경과 시간)에서 뚜렷한 차이가 길이 하나뿐이고 그것도 반례가 있으니, 다음 회차는
상위 10개 블로그의 전체 글 수·개설일을 재서 우리(52편+)와 비교한다.
