# 영상 디자인 기준 v3 — 잘된 채널 실측 대비 (2026-10-16 영상 디자인 총괄)

사장님(10/16 18:1x): "문구나 꾸민 건 다른 잘되는 채널들 참고한 거 맞아? 자막 위치나 크기나 색이나 도형이나."
답: 지금까지는 **안 쟀다.** 자막 쪼개기·장소 사진만 경쟁을 봤고, 흰 판·검은 자막 상자·주황 답 띠·자막 크기·위치는 우리가 정한 값이었다. 이 문서가 처음 같은 잣대로 잰 값이다.

## 0. 무엇을 어떻게 쟀나
- **고른 법**: 유튜브 Data API search.list(order=viewCount, 최근 30일, regionCode KR, 한국어) 8개 검색어(주식·부동산·아파트·경제·재테크·ETF 배당·금값·환율 금리) × 길이 3종 = 24회, 후보 1,119편 + `research/longform/loop/outliers_latest.json` 125편. 조회 순으로 돈·경제·부동산·주식 **정보** 영상만(드라마·연예·동물·정치 발언 클립 제외), 채널당 1편, 세로 쇼츠만(가로 뉴스 클립 3편 tqiOAVInzF4·4eUcDTN703w·9IPmLDIIiYk는 세로가 아니라 뺌).
- **받은 것**: yt-dlp로 쇼츠 10편 전체(720×1280), 롱폼 5편은 0~180초 + 가운데 90초 구간(1280×720). 화면 캡처는 scratchpad에만 있다(저장소에 넣지 않음).
- **재는 법**(scratchpad `ds/scripts/measure.py`·`analyze.py`·`cuts2.py`):
  - 1초마다 한 장(롱폼 3편은 3초) → RapidOCR 글자 찾기(읽기 안 함)로 글자 줄 상자 → 줄마다 k-means 3색으로 글자 색·바탕 색, 글자 픽셀 위아래 끝으로 **글자 높이(화면 높이 %)**.
  - 같은 자리에 프레임 40% 넘게 있는 줄 = 고정 글자(위 제목·채널명), 나머지 = 바뀌는 글자. 쇼츠는 화면 35~85% 높이·가로 가운데에서 가장 자주 나오는 바뀌는 줄 띠 = **자막**.
  - 한 줄 글자 수 = 줄 너비 ÷ (글자 높이 × 0.95) 어림(한글 한 자는 거의 정사각형). OCR로 읽은 수가 아니라 **어림**이다.
  - 테두리·그림자·상자는 자동 판정이 흔들려서(밝기 고리 방식) **자막 띠를 크게 잘라 눈으로** 봤다(편마다 길이의 30%·55%·80% 지점 3장).
  - 장면 바뀜: 0.2초마다 8×14칸(가로 영상은 14×8), 칸 25% 넘게 밝기 25 넘게 바뀌면 컷. 자막만 바뀌는 것은 안 잡힌다.
- **우리**: 같은 스크립트로 예약 쇼츠 12편 렌더본(work/video/out/*_sz2_ds.mp4) 전부. 롱폼은 TallyFrame 코드 값(work/video/src/motion/TallyFrame.tsx)과 caption-spec-1011.md 실측(같은 방법, 1080p 34~39px 대조)을 쓴다. N-2 시범은 ep/N-2/pilot/preview 장면 4장.

## 4. 차이 핵심 (숫자)
1. **배경**: 경쟁 쇼츠 9/10·롱폼 5/5가 실사. 우리 쇼츠 실사 2/12(C2P 두 편만), 롱폼 0/2(장 머리 빼고).
2. **자막 크기**: 경쟁 쇼츠 글자 높이 3.28%, 우리 C1S·M1S 2.29% — 0.7배. (롱폼은 4.9% vs 4.2%로 이미 같은 급)
3. **자막 꾸밈**: 경쟁 8/9가 상자 없이 흰 글자+검은 테두리. 우리 10/12가 검은 둥근 상자.
4. **장면 바뀜**: 경쟁 쇼츠 장면 중앙 5.0초. 우리 C1S·M1S는 화면 컷 0, 판 하나가 8~27초 간다.
5. **위 제목**: 경쟁 글자 높이 4.6%, 둘째 줄 통째 색(노랑·주황·초록) 6/10. 우리 3.5%, 핵심 낱말만 노랑. 위치는 경쟁 첫 줄 12.2%가 유튜브 위 UI 자리(15%) 안이라 우리는 따르지 않는다(안전 영역 우선).
6. 위치는 이미 맞다: 자막 가운데 경쟁 61.6% vs 우리 61.1%. C2P만 54.2%로 높고 2~3줄.
7. 큰 숫자 칸: 경쟁 쇼츠 0/10. 우리는 전 편(주황 답 숫자). → 브랜드 정체성(숫자1+행동1)이라 **유지**한다. 대신 숫자 칸 말고 자막 속 숫자도 노랑으로 맞춘다.
