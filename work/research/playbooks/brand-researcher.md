# 브랜드 리서처 교본 (firemap-brand-researcher) — v1 2026-09-30

> 매 회차 시작에 lessons.md 다음으로 읽는다. 끝나면 '배운 것'에 1줄 이상.
> 이 자리는 브랜드 디렉터가 결정할 수 있도록 **사람에 대한 근거**를 모은다: 우리 시청자·카페 회원·검색자가 누구고 무엇에 반응하는가. 하루 한 주제씩 돌아가며(우리 시청자 → 경쟁 채널 반응 → 검색자 → 사이트·카페 → 정리).

## 1. 이 자리 전문가가 아는 것

1. **페르소나는 조사에서 나온다. 상상에서가 아니다.** NN/g: 페르소나는 전형적 사용자에 대한 허구지만 현실적인 묘사이고, 사용자 조사에 근거해야 하며, 설계 결정에 쓰이지 않는 세부는 뺀다. 담는 것: 상황, 목표·걱정, 경험 수준, 대표 발언.
   - 출처: https://www.nngroup.com/articles/persona/
2. **사람들은 훑어 읽는다. 무엇에 멈추는지가 데이터다.** 서식 단서가 없고 빨리 끝내고 싶을 때 F자로 훑는다. 댓글·검색어에서 '멈추게 한 말'을 모은다.
   - 출처: https://www.nngroup.com/articles/f-shaped-pattern-reading-web-content/
3. **유튜브 분석은 늦게 쌓이고, 조회 숫자의 뜻이 바뀌었다.** 도입부·핵심 장면 지표는 60초 이상·조회 100 이상 영상에서만, 1~2일 늦게 나온다. 2026-08-24부터 조회는 재생 시작 순간 센다 — 8월 전 숫자와 바로 비교하지 않는다.
   - 출처: https://support.google.com/youtube/answer/9314415 · https://blog.youtube/inside-youtube/engaged-views-youtube-explained/
4. **클릭률의 보통 범위를 알고 해석한다.** 채널·영상 절반이 2~10%. 홈 노출이 많으면 낮게 나온다. 새 영상·조회 100 미만은 흔들린다.
   - 출처: https://support.google.com/youtube/answer/7628154
5. **댓글 수집은 공식 API로, 할당량 안에서.** Data API 읽기는 보통 1단위, 하루 기본 10,000단위. 남는 할당량은 업로드용으로 남긴다.
   - 출처: https://developers.google.com/youtube/v3/determine_quota_cost
6. **네이버 데이터는 공식 경로만.** 네이버 약관은 사전 허락 없는 자동화 수단(매크로·봇)으로 검색·수집하는 것을 금지한다. 검색어는 검색광고 API(kwvol.py), 카페는 우리 카페 관리 데이터만.
   - 출처: https://policy.naver.com/policy/service.html
7. **표본이 작으면 결론이 아니라 가설이다.** 30개 미만으로 "모두·전혀"를 쓰지 않는다. 놀라운 숫자는 다시 잰다(트와이먼의 법칙).
   - 출처: https://hbr.org/2017/09/the-surprising-power-of-online-experiments

## 2. 넘기기 전 체크리스트

- [ ] 이번 회차 주제 하나를 끝까지(시청자·경쟁 반응·검색자·사이트카페 중 순번).
- [ ] 숫자마다 출처(도구·API·파일)와 측정 시각. 못 잰 것은 '확인 안 함'.
- [ ] 경쟁 댓글: 인기 영상 댓글 상위 50개(commentThreads). 좋아함·불만·쓰는 말을 각각 요지로. 작성자 이름·아이디 기록 금지.
- [ ] 검색어: 핵심어 주변어 월 검색수(예: 은퇴 vs 파이어 vs 노후) — kwvol.py 숫자 그대로.
- [ ] 사이트: firemap_events(파이어맵 Supabase c7cd8a90)에서 방문·계산 완료·공유. 내부 방문(?fm_internal=1) 제외 확인.
- [ ] 카페: 가입 질문 답, 방문자 연령·성별·유입(카페 관리 통계). 9/22~26 실측: 비멤버 방문 1,736·가입 0, 45~49세 최다, 남 60%, 모바일 홈판 유입 31~50%(cafe-strategy.md).
- [ ] persona.md: 사람 3유형 — 원하는 것, 쓰는 말, 반응한 콘텐츠, 근거 숫자.
- [ ] today.md에 브랜드 디렉터용 "이번 주 새로 알게 된 것 3가지".
- [ ] 표본 수를 함께 적었다. 30 미만이면 '가설'.
