## 2. 숫자 표기 1규칙 (부품 #2 Amount가 강제)
1. **결과·내역 = 원 단위 전체 + 쉼표**: `3,621,410원`. 결과 숫자에 '만'을 쓰지 않는다(정확한 값이 이 사이트의 이유).
2. **입력값 옆 읽기 도움 = 만·억 한글**: 입력 `40,000,000` 밑 `4,000만 원`(토스 송금 입력 방식). 억 이상은 `2억 5,000만 원`.
3. **칩 = 증감만, 같은 단위**: `+100만`·`+1,000만`·`+1억` — 쉼표 넣음, '원' 뺌.
4. 퍼센트: 소수 1자리 `4.0%`, 정수면 `21%`. 나이 `65세`, 기간 `180일`.
5. 한 카드 안에 1과 2를 섞지 않는다. 기본값이 0인 칸은 `0원`이 아니라 `—`(빈 상태).

## 4. 조립 규칙 (한 화면)
1. 모바일 위에서부터: TopBar → TitleBlock → **ResultCard(+NextStep)** → 입력(Segmented 맨 위, 바탕 위에 바로 — 입력 감싸는 카드 없음) → BreakdownList 접힘 → (AdSlot, 상품 있을 때만) → Fold(계산 방법) → SourceLine → 바닥글. 기본값으로 이미 계산된 결과가 먼저 보인다.
   데스크톱 1024↑: 7:5 격자, 왼쪽 입력 카드(회색 바탕·흰 칸), 오른쪽 결과 열 sticky(ResultCard → BreakdownList), 아래 계산 방법·근거는 입력 열 폭, 바닥글 전체 폭, 머리 메뉴(연봉·퇴직금·실업급여, 현재 위치 2px 밑줄 본문색).
2. 375px 첫 화면(812 높이) 안에 **입력 전부 + 결과 숫자**가 들어가야 한다. 안 들어가면 입력을 줄인다(접힌 '더 자세히'로).
