== 1. 주담대 최대한도 (금융위 2025-10-15, 10월 16일 시행) ==
수도권·규제지역 주택구입목적 주담대 한도(종전 6억원)를 시가에 따라 차등: 15억원 이하 6억원 · 15억원 초과~25억원 이하 4억원 · 25억원 초과 2억원. 이주비대출은 주택가격 무관 6억원.
== 2. 스트레스 금리 (같은 자료) ==
DSR 산정 시 대출금리에 가산하는 스트레스 금리 하한을 수도권·규제지역 주담대에 한해 1.5%에서 3%로 상향(10월 16일). 실제 대출금리에는 미반영. 비규제 수도권·지방은 하한 1.5%~상한 3.0%(지방 주담대 0.75%).
== 3. LTV (같은 자료) ==
규제지역 주담대 LTV 70% → 40%. 
== 4. DSR 비율 ==
은행권 40% (금융위 가계부채 관리 강화방안 Q&A, 2021-10-26, dsrcalc/pkg/facts.txt에서 확인). 총대출 1억원 초과 차주.
== 5. 은행 주담대 금리 (finlife 202609, 담보 아파트·분할상환) ==
옵션 45개·은행 17곳. 변동금리 26개 최저금리 중앙 4.96% (4.20~5.64). 고정금리 19개 최저금리 중앙 5.55% (4.97~6.43).
== 6. 계산 [계산] 30년 원리금균등, 변동 4.96%, DSR 40%, 다른 대출 없음 ==
연봉 5,000만: 스트레스 없음 3억 1,189만 / 3%p 얹으면 2억 2,801만 / 8,388만 감소(26.9%) / 2억 2,801만 빌리면 실제 월상환 122만
연봉 7,000만: 4억 3,664만 / 3억 1,921만 / 1억 1,744만 감소 / 월 171만
연봉 1억: 6억 2,378만 / 4억 5,601만 / 1억 6,777만 감소 / 월 244만
연봉 1억 5천: 9억 3,566만 / 6억 8,402만 / 2억 5,165만 감소 / 월 366만
6억원을 스트레스 3%p 얹고도 받으려면 연소득 1억 3,158만원. 6억원 실제 월상환 321만원.
LTV 40%로 6억 = 집값 15억원 [계산 6/0.4]. 15억 초과 주택은 한도 4억.
