**나이·금액·상황을 밝히고 묻는다.** "34살 주식 1개월차", "만 40 싱글", "금융자산 11억".

우리 글에는 사람이 없다. 숫자만 있다.
```
27회  금융소득 2천만원 넘으면, 소득세법은 이렇게 계산합니다
14회  진주는 910만원인데 성남은 7억 가까이…
```
그쪽 카페의 **"금융소득을 조회해 보다가..."는 조회 2,721회**다. 우리 27회짜리와 **같은 주제**인데 100배 차이다.
주제가 문제가 아니라 **누가 왜 쓰느냐**가 다르다.

## 그래서 할 일

### 1. 게시판을 묶음으로 나눈다 (많이가 아니라 길을 내려고)
```
[정보]   미국주식·ETF / 배당·현금흐름 / 부동산 / 세금·연금
[이야기] 질문·고민 / 내 포트폴리오 / 파이어 이야기
[운영]   공지
```
지금 자유게시판 하나에 24편이 쌓여 배당 글 보러 온 사람이 부동산 글 사이에서 헤맨다.

### 2. 회원이 쓸 자리를 먼저 만든다
운영자 정보글만으로는 조회가 안 나온다는 게 숫자로 나왔다(글 89편 게시판 946회 vs 5편 게시판 2,321회).
**질문·고민**과 **내 포트폴리오** 게시판이 그 자리다. 댓글이 생길 유일한 곳이다.

### 3. 정보글에 사람을 넣는다
우리가 쓰는 글은 계속 정보글이다. 다만 "누가 왜 궁금한지"를 첫 줄에 놓는다.
지어내지 않는다 — 우리가 실제로 계산하다 막힌 대목, 자료가 안 맞았던 대목을 쓴다.

### 4. 가입 이유를 만든다
전체공개라 다 읽고 그냥 나간다. **자료 성격이 강한 글(단지표·종목표·계산 결과)만**
멤버공개로 돌린다. 전부는 안 된다 — 검색 유입이 끊긴다.

### 5. 수익화는 등급이 오른 뒤
광고 수익은 **가지 등급부터**(관리 화면 문구). 우리는 씨앗2단계다.
쿠팡파트너스는 멤버 1명한테 붙여야 누를 사람이 없다.

## 확인 못 한 것
- 가지 등급 승급에 필요한 정확한 숫자. 네이버가 공개하지 않는다.
  관리 화면에도 "씨앗2단계"라고만 뜨고 다음 조건이 없다. 네이버 검색으로도 공식 문서가 안 나온다.
