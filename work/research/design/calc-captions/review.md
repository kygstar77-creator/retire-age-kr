# 계산기 3종 결과 화면 캡션·은퇴 버튼·'재직 N일' 판정 (firemap-designer, 2026-10-01 10:3x)

기준: 브랜드 guide ③·메모리 design-identity '설명 캡션 금지(라벨·숫자·버튼·가정값만)'. 새 말은 짓지 않는다 — 아래 문구는 모두 지금 화면에 있는 단어를 줄이거나 옮긴 것. 글자 최종은 editor-web.

## 1. 연봉 결과 (SalaryCalc.jsx) — 디자인 통과(아래 안대로 적용 시)
| 자리 | 지금 | 안 |
|---|---|---|
| 다크 카드 칩 아래(56행) | "원천징수 비율 · 기본은 100%예요 · 회사에 신청하면 80% · 120%도 돼요" 2~3줄 | 칩 바로 위 라벨 **"원천징수 비율"** 1줄(ds-hero__sub 크기 그대로). 나머지 문장은 그대로 **'계산 방법' 카드 끝으로 옮김** |
| 주황 버튼 아래 회색(61~63행) | "실수령 …에서 생활비 …를 빼고 남는 …을 월 저축으로 넣어 계산해요 · 생활비는 아래에서 바꿔요" 3줄 | **가정값 1줄:** `생활비 2,500,000원 · 월 저축 435,813원` (저축 0이면 `월 저축 0원`). 원래 문장은 '계산 방법' 카드로 옮김 |
- 이유: 결과 카드 아래 회색 3줄이 버튼과 입력 사이를 밀어 320px에서 입력 카드 시작이 y≈880(f3-a-prod-320.png). 1줄이면 약 50px 위로.
- 타일 '세액표 100%'는 칩 상태와 같은 값 두 번 — 칩이 있으니 타일 셋째 칸은 빼도 된다(product-dev 재량, 빼면 타일 2칸).

## 2. 퇴직금 '재직 N일' 중복 (editor-web 요청) — 판정
- 큰 숫자 아래 줄을 **`재직 약 N년`** 으로(일수 빼기). 타일 '재직일수'는 '계산 방법' 식(재직일수 ÷ 365)의 재료라 남긴다. 1년 미만은 원래 경고 문장이 나오므로 빈 경우 없음.

## 3. 퇴직금·실업급여 '이 돈이면 몇 살에 은퇴?' (planner ①) — 재사용 기준 확인
- 연봉 A안 패턴 = 결과 카드(StatHero) **바로 아래** 주황 Button lg full 1개 + 가정값 1줄. 다크 Card·SectionHead로 감싸지 않는다.
- 퇴직금: 지금 입력 카드 아래 다크 카드(81~86행)를 없애고 버튼을 StatHero 바로 아래로 **옮긴다**(새로 더하지 않음 — 주황 행동 1개 유지). 가정값 1줄 `현재 자산 + 퇴직금 N원`.
- 실업급여: 같은 자리. 버튼 글자는 bc7b7e5에서 재취업 맥락으로 바꾼 이유(고용보험법 제40조)가 있으니 editor-web이 기존 말 '재취업 뒤, 몇 살에 은퇴할 수 있을까?' 유지 여부를 정한다. 320px에서 버튼 글자 1줄이 조건(넘으면 '이 돈이면 몇 살에 은퇴?' + 가정값 줄 `재취업 뒤 · 현재 자산 + 실업급여 N원`).
- 이 기준대로 구현 캡처(320·375 라이트·다크)가 오면 시안 없이 검수만 한다(기존 부품만 쓰는 작은 변경).
- 예술가 반려(버튼만으로는 뻔함)는 그대로 유효 — 이 버튼은 21번 통과로 치지 않는다.
