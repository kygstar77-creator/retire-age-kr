# X-KR-1 판매 전 법 전제 확인 (국내 시장조사원, 2026-10-01 09:2x)

## 결정안
엑셀 가계부 템플릿 1종(월 지출 입력 → 파이어맵 은퇴 계산 식으로 필요 자산·은퇴 나이 표시)을 9,900원에 리틀리(litt.ly)에서 판다. 결제 즉시 구매자 이메일로 파일이 자동 발송된다. 판매자는 사장님 개인(사업자등록 여부 확인 안 함). 유입은 firemap.kr 계산기 결과 아래 링크 1개와 유튜브 설명란. 템플릿·판매 문구에 종목·매매 조언은 없다.

## 확인한 원문
1. 전자상거래법 제12조① [공식, lawtext.py]: 통신판매업자는 신고해야 한다. "다만, 통신판매의 거래횟수, 거래규모 등이 공정거래위원회가 고시로 정하는 기준 이하인 경우에는 그러하지 아니하다."
2. 공정위 고시 「통신판매업 신고 면제 기준에 대한 고시」(제2022-4호, 2022-04-05 시행, 현행) 제2조① [공식, law.go.kr DRF admrul ID 2100000210384]:
   "1. 직전년도 동안 통신판매의 거래횟수가 50회 미만인 경우 / 2. 「부가가치세법」 제2조제4호의 간이과세자인 경우" 중 하나면 신고를 아니할 수 있다. ② 청약철회 등은 거래횟수에 넣지 않는다.
3. 리틀리 공식 블로그(start.litt.ly/blog/online-selling-automation-guide, 09:2x 열람): "사업자 등록이 없어도 연 거래 건수 20건 이하라면 개인 판매자로 바로 시작할 수 있습니다." — 리틀리 자체 기준(고시 50회와 다름).
4. 전자상거래법 제17조②5호·⑥항(scout 1장 [공식]): 디지털콘텐츠 청약철회 제한은 '불가 사실 표시 + 시험 사용 상품 제공'이 있어야 한다.
5. 자본시장법 제101조①(유사투자자문업): 대가를 받고 간행물 등으로 금융투자상품 투자판단 조언을 업으로 하면 신고 대상.

## 묻고 싶은 것
- 첫 해(직전년도 거래 0회)에 통신판매업 신고 없이 팔 수 있나? 연 20건을 넘으면 리틀리에서 사업자등록이 필요해지는데, 그 시점에 통신판매업 신고도 같이 해야 하나?
- 사업자등록 없이 개인이 반복 판매하면 세법(사업소득·부가세) 문제가 있나?
- '은퇴 나이·필요 자산' 계산 결과가 자본시장법 투자판단 조언으로 보일 위험은?
- 표시광고법·전자상거래법상 판매 페이지에 꼭 들어가야 할 표시(판매자 신원, 청약철회 제한 고지, 미리보기)는?
