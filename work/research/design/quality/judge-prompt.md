2. **375px 실제 캡처** — 시안(HTML·Figma)이면 375px로 렌더한 캡처. 데스크톱 캡처만 있으면 무효.
3. 심사위원 3명이 **서로의 답을 보지 않고** 매긴다(diagnosis.md·이전 점수 안 보여 줌).
4. 점수 옆에 **모델명**을 적는다. 제미나이 lite와 flash는 같은 화면에 2~3점 차이가 난다(lessons 10/02 07:2x) — 비교는 같은 모델끼리만.

## 공통 질문 (세 명에게 같은 글)
```
당신은 한국 핀테크 앱(토스·뱅크샐러드) 수준을 아는 모바일 UI 심사위원입니다. 칭찬보다 깎을 이유부터 찾으세요.
첨부는 휴대폰 375px 화면 비교판입니다. '우리' 표시가 파이어맵(firemap.kr, 은퇴·돈 계산기) 화면, 나머지는
같은 일을 하는 화면(네이버 계산기 위젯 등)과 완성도 기준(토스·뱅크샐러드 첫 화면)입니다.
화면: {화면 이름과 주소}
한국어로, 정확히 이 형식:
1) 첫 줄 '점수: N' (1~10. 질문: 토스·뱅크샐러드 옆에 놓았을 때 같은 수준의 회사가 만든 것처럼 보이나.
   6 = 국내 개인 사이트 평균, 8 = 토스 옆에 놓아도 어색하지 않음, 10 = 구분 안 됨)

3) 8점으로 올릴 고칠 점 3개 — 무엇을 빼거나 합치거나 키울지 구체적으로
4) 한 줄: 이 화면에서 가장 먼저 눈이 가는 것 / 가야 하는 것(둘이 다르면 감점 이유)
```
