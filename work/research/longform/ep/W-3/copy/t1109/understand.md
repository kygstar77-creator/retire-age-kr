# W-3 제목 이해 시험 11/9 (copywriter) — 40세·50세·60세, 1차·2차, 새 심사관 Agent 6명
썸네일 글자 같음: 흰 '2026년부터 배당소득 분리과세' / 큰 '1년 배당·이자 2천만까지' / 주황 '넘는 사람만 세금 달라져요'
## 1차 — 11/8 1위(하이닉스 판) vs 2위(현대차 판), 판 순서 사람마다 바꿈
- 40세: 두 판 다 '회사가 대상'으로 읽음 · 뭘 하겠어요 → 2천만 넘는지 확인하려 누름 · 낚시 조금/조금 · 고름 하이닉스 · 남은 궁금증: 2천만 넘는지, 늘어나나 줄어드나
- 50세: 두 판 다 '모르겠다(대상일 수도)' · 뭘 하겠어요 → 눌러 보고 세무사에게 물을 것 적기 · 낚시 조금/조금 · 고름 현대차(익숙) · 남은 궁금증: 제목 회사가 들어가나
- 60세: 두 판 다 '대상'으로 읽음 · 뭘 하겠어요 → 2천만 넘는지 셈 · 낚시 조금/조금 · 고름 현대차 · 남은 궁금증: 어떤 경우 해당·얼마 달라지나
→ 둘 다 떨어짐(낚시 조금 3/3)
## 2차 — 새 후보 A·B·C, 순서 사람마다 바꿈
- 40세: A 뜻 맞음(하이닉스·현대차 아님 명시)·낚시 아니오·매매 아니오 / B 조금 / C 조금 · 고름 A
- 50세: A 뜻 맞음·낚시 아니오·매매 아니오 / B 조금 / C 조금 · 고름 A
- 60세: A 뜻 맞음·낚시 아니오·매매 아니오 / B 조금 / C 조금 · 고름 A
남은 궁금증: 배당·이자 2천만원이 안 되면 정말 그대로인지, 넘는지 어떻게 아는지(3명 공통)
판정: 통과 (A '삼성전자 배당금 세금, 하이닉스·현대차는 분리과세 대상 아니다… 달라지는 사람은 따로 있다')
