# 업무 흐름 설계안 — 업무 흐름 설계 TF (2026-10-01 08:1x)

사장님(08:0x): "순서도 사실 니가 직원들이랑 의논해서 최적의 방향으로 짰어야 하는 거 아니가."
근거: 직원 지시문 16개(10/1 추가 문단), today.md·decisions/log.md 10/1, lessons.md, launch-checklist.md, conductor-manual.md, X-OPS-1~5, 교본, 실제 예약 시각(list_scheduled_tasks 08:1x).
지금 순서: 조사 → 기획자+예술가 → 디자이너 → 제작 → 디자인·뻔함 통과 → 공개 → 측정. 모든 새 일에 같은 7단계를 건다.

**진단 3줄**
1. **느리다.** 운영실장은 [지시]와 '막힘'만 읽는다. [기획 요청]·[예술가 요청]·[디자인 검수 요청]·[뻔함 검수 요청]은 담당의 고정 근무를 기다린다. 실제 예약 시각으로 계산하면 08:00 조사 요청이 운영 반영까지 약 27시간 걸리고, 넘기는 횟수는 6번이다. 경로: 조사 09:20 → 기획 11:30 → 시안 16:20 → 제작 17:10 → 디자인 검수 다음 날 10:20 → 배포 11:10. 이 계산은 추정이다. '하루 1실험'과 맞지 않는다.
2. **같은 일을 여러 번 한다.** X-V1 하나에 경쟁 비교가 네 번 있었다(빌더 compare.md, 예술가 [제안], 기획서, launch-checklist 2·21번). '우리만 다른 한 가지'도 세 가지가 나왔다(세금 시계 / 다음 £1,000·60% 경고 / 다음 £1,000 한 줄). 기획자 본인도 적었다: "brief·launch·compare가 이미 기획의 대부분을 담고 있다."
3. **검수가 가장 비싼 끝에 있다.** 뻔함 반려가 제작이 끝난 뒤에 난다. conductor-manual은 "확인은 가치가 가장 낮은 초기 단계에서"라고 한다. 예술가는 기획 단계와 공개 직전에 같은 판정을 두 번 한다.

## 3. 태그·호출 규칙
**줄 형식(모든 태그 공통):** `[태그] <일 이름> 트랙:A|B · 담당 <task-id> · 시한 HH:MM · 근거 <경로>`
**답 줄:** `통과: <태그> <이름> HH:MM (task-id)` 또는 `반려: … — 고칠 점 ≤3`. 착수·완료 줄은 지금과 같다.
| 태그 | 쓰는 사람 | 받는 사람 | 시한 |
|---|---|---|---|
| [지시] | 순돌이·점검관·본부장만(배정) | 담당 | 적힌 시각 |
| [조사 요청] | 기획자·본부장 | 조사원·브랜드 리서처 | 3시간 |
| [예술가 요청] | 본부장(A)·기획자(B) | 예술가 | A 1시간 · B 3시간 |
| [기획 요청] | 본부장·본부장급·조사원은 **본부장 경유** | 기획자(B만) | 3시간 |
| [시안 요청] ('[요청] firemap-designer' 대체) | 기획자 | 디자이너(+카피·성장 동시) | 3시간 |
| [구현 요청] | 디자이너 | 제품 개발·빌더 | 6시간 |
| [디자인 검수 요청] | 제작 담당(캡처 경로 필수) | 디자이너 → 부재 시 브랜드 디렉터 | 1시간 |
| [뻔함 검수 요청] | B에서 기획서와 달라진 경우만 | 예술가 | 1시간 |
| [결재 필요] | 누구나(가장 이른 단계에서) | 순돌이 → approvals.md | 사장님 |
| 막힘 | 누구나 | 순돌이·운영실장 | 즉시 |

**누가 다음 사람을 부르나**
1. **끝낸 사람이 다음 태그를 직접 쓴다.** 예: 기획자가 완료하면서 [시안 요청]을 쓴다. 순돌이나 회의를 거치지 않는다(X-OPS 후보 '직원 간 직접 인계').
2. **운영실장(:05·:35)은 담당이 적혔고 착수 줄이 없는 모든 태그를 트리거로 본다.** 투입 순서: 막힘 → 공개 직전 검수 → [지시] 결승선 칸 → 나머지 태그. 검수 요청은 담당의 고정 근무를 기다리지 않는다.
3. 한 일은 한 compare.md와 한 기획 파일(A는 ventures/<slug>/brief.md, B는 plans/<이름>.md)만 쓴다. 다른 직원은 그 파일에 칸을 더하고 새 파일을 만들지 않는다.

**병목·멈춤 막기**
| 상황 | 규칙 |
|---|---|
| 태그에 30분 넘게 착수 줄 없음 | 다음 운영실장 회차가 1순위로 투입한다 |
| 한 단계가 **3시간 넘게** 안 움직임 | 점검관(:50)이 '정체 <단계> <시간>'으로 표시한다. A 검수는 **시한 통과**(사후 검수 24시간 안, 반려되면 되돌림). B는 해당 본부장이 진행·보류를 정한다. 사장님께 묻지 않는다 |
| 같은 반려 2번 | 본부장에게 올린다. 이틀 이어지면 지시문 재작성([총무 요청]) |
