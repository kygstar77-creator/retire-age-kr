
## home — 첫 화면 /
[모델 gemini-3.1-flash-lite]
모바일 UI 심사위원으로서 '파이어맵'의 첫 화면을 토스·뱅크샐러드와 같은 기준에서 냉정하게 분석합니다.

**점수: 6**

---

### 1. 점수를 깎은 이유 (UI/UX 결함)
1. **정보 구조의 단순함 대비 여백 과다:** 화면 상단 '파이어맵' 로고와 카드 사이, 그리고 하단 '카페/오픈채팅' 영역 사이에 불필요한 여백이 너무 많습니다. 375px 모바일 화면에서는 사용자에게 '첫 화면에서 제공할 정보가 이것뿐인가?'라는 느낌을 주어 신뢰도를 떨어뜨립니다.
2. **시각적 위계의 평이함:** 핵심 행동 유도 버튼(CTA)인 '내 파이어 나이 계산하기'가 너무 평범한 주황색 사각형입니다. 토스나 뱅크샐러드는 버튼의 그림자, 그라데이션, 혹은 라운딩 값을 통해 '누르고 싶게 만드는' 감각적인 UI를 구현하는데, 파이어맵은 단순히 '정보 입력 칸' 뒤에 버튼이 배치된 폼 양식처럼 보입니다.
3. **불균형한 시각적 무게:** 상단 카드 내부의 '1분 계산·가입 없음'이라는 텍스트가 너무 작고 흐릿합니다. 반면, 하단의 '카페·오픈채팅' 영역은 본 서비스와 위계상 분리되어야 함에도 불구하고, 마치 메인 서비스인 것처럼 큰 영역을 차지하고 있어 사용자의 시선을 분산시킵니다.

---

### 2. 8점으로 올릴 구체적 수정 제안
1. **상단 카드 영역의 대폭 확대 및 시각화:**
   * '내 파이어 나이 계산하기' 버튼을 화면 너비에 맞게 더 크게 키우고, 버튼 내부에 화살표 아이콘을 더 명확하게 처리하세요.
   * 입력 칸(현재 나이 35세)은 텍스트 필드 느낌을 줄이고, 토스처럼 **'숫자를 크게 강조하는'** 방식으로 디자인하여 사용자가 인터랙션하고 싶게 만들어야 합니다.
2. **하단 '카페·오픈채팅' 영역의 축소 및 분리:**
   * 현재의 큰 카드 형태는 메인 서비스의 집중도를 해칩니다. 이를 하단에 깔끔한 '텍스트 링크' 형태로 바꾸거나, 아예 '더보기/커뮤니티' 아이콘 버튼으로 축소하여 메인 서비스(계산기)가 화면 전체를 지배하게 만드세요.
3. **브랜딩 컬러와 폰트의 정교화:**
   * 현재 주황색 버튼의 색상이 다소 원색적입니다. 토스처럼 브랜드 아이덴티티를 살리되 톤 다운된 컬러나 그라데이션을 적용하세요. 또한, 본문의 폰트 크기를 키우고 줄 간격(Line-height)을 조절하여, 단순히 '웹페이지'가 아닌 '핀테크 앱'의 정갈함을 갖추어야 합니다. (하단에 작게 박힌 '개인정보처리방침' 등도 좀 더 옅은 회색으로 처리해 메인 콘텐츠의 시각적 간섭을 줄이세요.)

## salary — 연봉 실수령 계산기 /calc/salary
[모델 gemini-3.1-flash-lite]
모바일 UI 심사위원으로서 '파이어맵'의 연봉 실수령 계산기 화면을 토스·뱅크샐러드와 같은 핀테크 표준 관점에서 냉정하게 평가합니다.

**점수: 5**

---

### 1. 점수를 깎은 이유 (현 화면의 UI/UX 결함)

1.  **정보 밀집도 및 가독성 부족:** 상단 검은색 카드 내부에 '연봉 4,000만 · 비과세 월 20만 · 가족 1명 · 자녀 0명'이라는 텍스트가 너무 작고 다닥다닥 붙어 있어 가독성이 떨어집니다. 이는 사용자가 현재 계산 조건이 무엇인지 직관적으로 파악하는 것을 방해합니다.
2.  **컬러 팔레트 및 대비 문제:** 메인 액션 버튼(오렌지색)과 상단 정보 카드(다크 모드)의 톤이 서로 겉돕니다. 특히 검은색 배경의 정보창은 토스나 뱅샐의 화이트/라이트 블루 기반의 깔끔한 핀테크 UI와 비교했을 때 매우 무겁고 올드한 느낌을 줍니다.
3.  **UI 레이아웃의 불균형:** '원천징수 비율' 섹션의 버튼(80%, 100%, 120%)이 차지하는 면적 대비 하단 '이 돈이면 몇 살에 은퇴?' 버튼이 너무 크고 공격적입니다. 계산 결과 확인 후의 사용자 경험(UX) 흐름보다 특정 전환 유도(CTA)만 지나치게 강조되어, 정보 탐색의 편안함을 해칩니다.

---

### 2. 8점으로 올릴 고칠 점 3가지 (개선안)

1.  **상단 정보 카드 구조 개편 (계층화):** 현재 검은색 박스 안의 텍스트를 나열하지 말고, **키-값(Key-Value) 형태**로 정리하세요. 
    *   '연봉 4,000만 원'은 크게, 나머지 조건(비과세, 가족 수 등)은 하단에 작고 연한 텍스트로 깔끔하게 배치하여 사용자가 자신의 조건을 한눈에 인지할 수 있게 해야 합니다.
2.  **모던한 UI 컴포넌트로 교체:** 배경을 검은색이 아닌 화이트 또는 아주 연한 그레이(토스식 디자인)로 변경하세요. 
    *   '80%·100%·120%' 선택 영역은 현재의 박스 스타일 대신, **세그먼트 컨트롤(Segmented Control)** 디자인을 적용하여 핀테크 서비스 특유의 간결하고 세련된 느낌을 살려야 합니다.
3.  **CTA 버튼 최적화 (UX 흐름 고려):** '이 돈이면 몇 살에 은퇴?' 버튼을 현재처럼 큼지막하게 배치하기보다, 계산 결과 아래에 자연스럽게 녹아드는 **텍스트 링크나 부드러운 형태의 보조 버튼**으로 전환하세요. 
    *   사용자가 '계산 결과'라는 핵심 기능을 우선적으로 즐기게 하고, 은퇴 계산은 결과값을 기반으로 자연스럽게 이어지도록 설계해야 '광고'가 아닌 '기능'처럼 보입니다.

## severance — 퇴직금 계산기 /calc/severance
[모델 gemini-3.1-flash-lite]
모바일 UI 심사위원으로서 파이어맵(firemap)의 '퇴직금 계산기' 화면을 분석한 결과입니다.

**점수: 5**
(국내 평균 수준이나, 핀테크 앱의 표준인 '토스·뱅크샐러드'와 나란히 두었을 때 정보의 계층 구조와 정제미에서 차이가 큽니다.)

### 1. 점수를 깎은 이유 (UI/UX 결함)
1.  **정보 밀도의 불균형:** 최상단의 결과값 영역(8,812,388원)과 하단의 입력 폼 사이의 비례가 맞지 않습니다. 결과는 너무 작고 입력 폼은 한 번에 다 보여주려다 보니 화면이 지나치게 길어져서 '스크롤 피로도'가 높습니다.
2.  **버튼의 시각적 강조 오류:** 계산이 끝나지 않은 상태에서 '이 돈이면 몇 살에 은퇴?'라는 액션 버튼이 결과값 바로 아래 너무 크게 배치되어 있습니다. 사용자 흐름상 '계산하기'가 먼저여야 하는데, 계산도 하기 전에 다음 단계를 유도하는 것이 불필요하게 공격적입니다.
3.  **입력 필드의 완성도:** '입사일자·퇴직일자' 박스의 회색 배경과 입력 필드(박스 내 흰색)의 대비가 모던하지 않습니다. 또한 '1주 15시간 이상/미만' 선택 영역이 텍스트 라벨과 간격이 모호하게 붙어 있어 조작 편의성이 떨어져 보입니다.

### 2. 8점으로 올리기 위한 수정 제안 (Action Plan)
1.  **Bottom Action Sheet 도입:** 입력 폼을 한 페이지에 다 나열하지 마세요. '입력하기' 버튼을 누르면 화면 하단에서 입력창이 올라오는(Bottom Sheet) 형태를 취하거나, 스텝별(입사일 -> 급여입력 -> 결과)로 화면을 분리하여 핵심 결과값인 '퇴직금'이 상단에 항상 고정되게 만드세요.
2.  **타이포그래피 및 여백 최적화:** 토스나 뱅크샐러드는 '결과 숫자'의 가독성을 최우선합니다. 현재 결과값의 폰트 사이즈를 키우고, '재직일수/평균임금' 등의 부가 정보는 3단 그리드를 유지하되 아이콘이나 차트를 더해 시각적인 '핀테크스러운' 맛을 살리세요. (현재는 문서 양식처럼 보입니다.)
3.  **입력폼 레이아웃의 고도화:** '입사일자'와 '퇴직일자'를 위아래가 아닌, 좌우 배치(50%씩)로 조정하여 세로 공간을 확보하세요. 또한, 선택지(1주 15시간 이상 등)는 현재의 단순 버튼보다 **세그먼트 컨트롤(Segmented Control)** 디자인을 적용하여 뱅크샐러드의 탭 메뉴처럼 깔끔하고 클릭하기 좋게 만드세요.

**한 줄 평:** 엑셀 시트를 모바일로 옮겨놓은 듯한 '계산서' 느낌을 지우고, 사용자가 자신의 자산을 조회하는 '금융 서비스' 느낌으로 디자인 언어를 업그레이드해야 합니다.

## unemp — 실업급여 계산기 /calc/unemployment-benefit
[모델 gemini-3.1-flash-lite]
모바일 UI 심사위원으로서 파이어맵(firemap)의 '실업급여 계산기' 화면을 분석한 결과입니다.

**점수: 6**

### 1) 점수를 깎은 이유 3가지
1.  **정보 위계(Hierarchy)의 모호함**: 상단 결과값(예상 실업급여 총액)은 중요한 정보임에도, 그 아래에 나열된 세부 정보(법령, 날짜 등)와 폰트 크기 및 두께 차이가 크지 않아 시선이 분산됩니다. 핵심 정보가 '짠'하고 나타나는 임팩트가 부족합니다.
2.  **입력 폼 디자인의 노후화**: 날짜 선택이나 나이 선택 버튼이 전형적인 웹 폼의 형태입니다. 토스나 뱅크샐러드는 모바일 터치 환경에 최적화된 큰 버튼과 직관적인 슬라이더를 사용하는데, 현재는 '클릭' 중심의 웹 화면을 그대로 옮겨놓은 듯한 느낌을 줍니다.
3.  **불필요한 텍스트 오버로드**: "고용보험법 제45조..."와 같은 법적 근거 문구는 결과 영역 상단에 배치하기보다, 하단 '도움말'이나 '작은 글씨의 주석'으로 처리해야 합니다. 화면 상단은 사용자가 가장 궁금해하는 '얼마를 받는가'에 집중되어야 합니다.

### 2) 8점으로 올릴 고칠 점 3가지
1.  **결과값 카드(Result Card) 강조**: 가장 상단의 '11,888,640원'을 화면 중앙에 큰 볼드체로 배치하고, 배경을 은은한 브랜드 컬러(예: 파이어맵의 테마 색상)가 들어간 카드 형태로 감싸 '결과'임을 명확히 하세요. 부수적인 법령 문구는 해당 카드 하단에 연한 회색으로 작게 배치해 시선을 뺏지 않게 하세요.
2.  **입력 인터페이스의 고도화**: 현재의 텍스트 기반 선택지를 토스 스타일의 '토글(Toggle)' 또는 '선택 카드'로 변경하세요. 특히 '50세 미만/이상' 버튼을 더 크고 둥근 형태의 토글로 만들어 손가락으로 누르기 쉽게 개선하면 사용자 경험이 즉시 개선됩니다.
3.  **정보의 모듈화(Spacing)**: 각 섹션 간의 여백(Padding)을 지금보다 1.5배 이상 넓히고, 각 섹션(결과 영역 / 입력 영역 / 보험기간 설정)을 카드 형태로 분리하여 시각적 구획을 확실히 하세요. 지금은 정보들이 나열된 느낌이라면, 개선 후에는 앱의 '기능 모듈'이 정돈된 느낌을 주어야 합니다.

## guide — 가이드 목록 /guide/
[모델 gemini-3.1-flash-lite]
모바일 UI 심사위원으로서 파이어맵(firemap.kr)의 '가이드 목록' 화면을 토스/뱅크샐러드와 같은 핀테크 앱의 기준에서 냉정하게 분석해 드립니다.

### 1) 점수: 5

### 2) 점수를 깎은 이유
*   **지나치게 텍스트 중심적인 레이아웃:** 토스나 뱅크샐러드는 시각적 요소(아이콘, 카드, 이미지)를 활용해 정보를 빠르게 전달합니다. 반면 현재 화면은 문서(Document) 형태에 가까워 사용자가 내용을 훑어보기(Scanning) 매우 어렵고 정보 밀도가 낮아 보입니다.
*   **웹 표준(HTML) 기반의 기본 스타일:** 헤더의 텍스트 버튼('← 파이어맵 계산기'), 기본 불렛 포인트 리스트, 폰트 굵기 등에서 2010년대 초반 블로그나 게시판의 느낌이 납니다. 이는 사용자로 하여금 '신뢰할 수 있는 금융 앱'보다는 '개인 기록물'이라는 인상을 줍니다.
*   **계층 구조(Hierarchy) 부족:** 화면 상단의 제목과 하단 리스트 사이의 여백이 단조롭고, 항목들 간의 우선순위가 시각적으로 구분되지 않습니다. 핀테크 앱은 폰트 크기, 색상, 여백의 대비를 활용해 중요도를 나타내는데, 현재는 모두 같은 비중으로 나열되어 있어 가독성이 떨어집니다.

### 3) 8점으로 올릴 고칠 점
*   **리스트를 '카드(Card)' UI로 전환:** 단순 텍스트 링크 리스트를 각각의 카드 형태로 변경하십시오. 각 카드에 핵심 내용을 암시하는 심플한 아이콘(예: 자산 배분은 파이 차트 아이콘, 은퇴 준비는 달력 아이콘 등)을 배치하여 시각적 인지 속도를 높여야 합니다.
*   **헤더와 타이틀 영역 정돈:** 상단의 '← 파이어맵 계산기'라는 텍스트 네비게이션을 제거하거나, 앱 형태의 상단바(Navigation Bar) 스타일로 정돈하세요. 화면 제목인 '파이어 백과'를 훨씬 더 크고 굵은 폰트로 상단에 강조하여 사용자가 지금 어디에 있는지 즉각적으로 인지하게 만드십시오.
*   **여백(Spacing)과 폰트 시스템 적용:** 현재 텍스트들이 빽빽하게 붙어있습니다. 각 항목 간의 여백을 2배 이상 늘리고, 제목과 본문(요약 텍스트)의 폰트 사이즈 및 컬러를 확실히 구분(대비)하세요. 핀테크 앱의 핵심은 '깔끔함'입니다. 배경색은 완전한 흰색보다 미세하게 톤 다운된 라이트 그레이(F9F9F9 등)를 사용하면 훨씬 현대적인 느낌을 줄 수 있습니다.
