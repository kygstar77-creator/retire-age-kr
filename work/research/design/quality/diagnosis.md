## 화면별 못생긴 이유 (각 5개, 캡처에서 눈으로 확인한 것만)

### 연봉 계산기 (/calc/salary)
1. **숫자 1 원칙이 깨졌다.** 다크카드 하나에 큰 숫자 1개, 작은 숫자 3개, 80/100/120% 토글, 설명 2줄이 다 들어 있다. 반면 네이버는 결과 칸이 입력 아래에 하나만 있다.
2. **그릇 모양이 4가지다.** 다크카드, 흰 카드, 카드 없는 표('한 달 공제 6가지'), 회색 경고 박스, 광고 박스가 섞여 있다. 그래서 한 회사 화면으로 안 보인다.
3. **글이 세 겹이다.** 구역마다 회색 머리말('연봉 실수령액 계산기'), 굵은 제목('연봉·비과세액'), 설명이 쌓인다. 머리말은 맨 위 제목과 같은 말이다.
4. **숫자 표기가 섞였다.** '3,523만', '397,520원', '4,000만', '250만', '2억'이 한 화면에 있다. 단위와 자릿수 규칙이 없다.
5. **작은 회색 글이 너무 많다.**
   - 주황 버튼 바로 밑 3줄, 슬라이더 눈금(0원·2억), '계산 방법' 문단이 모두 11~12px 회색이다.
   - 네이버도 회색 글이 있지만 결과 아래 2줄뿐이다.

### 퇴직금 계산기 (/calc/severance)
1. 결과 카드가 **흰색**이다(연봉은 다크). 계산기 3종의 결과 카드 모양이 서로 다르다.
2. 날짜 입력이 브라우저 기본 모양이다(달력 아이콘, 테두리). 그래서 이 칸만 다른 앱 같다.
3. 결과 아래 작은 숫자 3칸(재직일수·1일 평균임금·3개월 총일수)은 사용자가 묻지 않은 중간값이다. 큰 숫자와 힘을 다툰다.
4. 주황 버튼 아래 '현재 자산 + 퇴직금 8,812,388원' 회색 한 줄이 버튼 설명인지 결과인지 알 수 없다.
5. 위 연봉과 같은 세 겹 글('퇴직금 계산기 / 입사일자·퇴직일자 / 설명')이 있다.

### 실업급여 계산기 (/calc/unemployment-benefit)
1. 결과 아래 3칸 중 '상한·하한' 칸 값이 '180일 하한 66,048원'으로 붙어 보인다. 칸 경계와 정렬이 깨졌다.
2. 큰 숫자 밑에 '고용보험법 제45조·제46조·제50조·2026-09-30 기준'이 바로 붙어 있다. 근거 문구가 결과 자리를 먹는다(네이버는 맨 아래 회색).
3. 결과 카드가 흰색이라 연봉 계산기와 다르다. 퇴직금 계산기와는 같다.
4. 날짜 입력이 브라우저 기본 모양이다(퇴직금과 같은 문제).
5. 375px 첫 화면에 입력이 1.5개만 보인다. 네이버는 첫 화면에 입력 3개와 계산 버튼이 다 보인다. 우리는 입력을 끝까지 내려야 한다.

### 첫 화면 (/)
1. 첫 화면 아래 절반이 '카페·오픈채팅' 링크 두 줄과 빈 회색이다. 반면 토스·뱅크샐러드는 첫 화면 전체를 한 장면(사진 또는 그래픽)으로 채운다.
2. **눈이 처음 멈출 그림이나 숫자가 없다.**
   - 제목 '나는 몇 살에 파이어할 수 있을까?'만 있다.
   - 결과 예시(예: '평균 파이어 50세')는 버튼 밑 회색 작은 글로 숨어 있다.
3. 나이 입력(− 35 +)이 제목보다 눈에 덜 띈다. 그런데 행동은 이것 하나다.
4. 로고 옆 불꽃 아이콘이 작고 색이 주황 하나다. 반면 토스·뱅크샐러드 로고는 크기와 여백이 정돈돼 있다(비교판 상단).
5. 카드 안에 또 회색 칸(나이 입력 박스)이 있다. 둥근 상자 안에 둥근 상자라서 겹 테두리 느낌이 난다.

### 가이드 목록 (/guide/)
- 비교판(compare-guide.png)만 만들었다. 판독은 **확인 안 함**. 디자이너 몫이다.

### 배당으로 파이어 (/dividend)
1. 375px 첫 화면에 **결과가 없다.** 입력 3개(자산·수익률·월 적립)가 슬라이더+눈금+칩 3~4개씩 쌓이고, 결과 다크카드 '아직'은 맨 아래에 머리만 보인다.
2. 입력 하나에 부품이 4겹이다: 라벨+값 칩(연필 아이콘) → 슬라이더 → 0원/30억 눈금 → +1000만·+1억·+10억 칩.
3. 회색 머리말 '내 조건' + 굵은 제목 + 설명 한 줄 — 연봉 계산기와 같은 세 겹 글.
4. 칩 두 종류가 섞였다. 금액 증감 칩(+1000만)과 상품 예시 칩(S&P500 1.3%·JEPI 8.4%)이 같은 모양이라 누르면 무엇이 되는지 다르다.
5. 숫자 표기: '3억'·'30억'·'+1000만'(쉼표 없음)·'50만'. 쉼표 규칙이 연봉 화면('4,000만')과 다르다.

### 국민연금 조기수령 (/pension)
1. 결과 카드가 **흰색**이고 큰 숫자가 '100만'(원 생략). 아래 3칸 '100만·0%·0원'은 첫 값과 같은 숫자를 다시 보여 준다.
2. 주황 버튼 '나이를 65세보다 낮추면 반영할 수 있어요'가 **연한 주황(비활성처럼)** 이고 두 줄로 꺾였다. 버튼인지 안내인지 모른다.
3. 경고 박스(⚠ 2026-09-30 기준·참고용)와 아래 회색 두 줄 설명이 연달아 있다 — 작은 회색 글 4줄.
4. 슬라이더가 끝(65세)에 붙은 채 시작한다. 바꿀 수 있는 쪽이 왼쪽뿐이라는 단서가 없다.
5. 같은 화면 안에 '65세부터 받으면 월'(머리말)과 '받기 시작 나이'(입력 라벨)가 같은 뜻을 두 번 말한다.

### 파이어 후 건보료 (/health-insurance)
1. 다크 결과 카드에 '2만'과 0원 3칸 — 기본값 상태 결과가 '2만'인데 근거 3칸이 전부 0원이라 숫자를 못 믿게 한다.
2. 결과 카드 머리말 '피부양자 유지 가능 · 지역가입자로 전환되면 월'이 한 줄에 두 판정을 붙였다(작은 회색 13px).
3. 탭(완전 은퇴/바리스타 파이어)이 결과 카드 **아래**에 있다. 결과를 바꾸는 선택인데 결과 뒤에 온다.
4. 입력마다 슬라이더+칩 3개+아래 회색 설명 — 배당과 같은 4겹.
5. 375px 첫 화면에 입력 2개가 0원으로 반쯤 보이고 끝난다. 무엇을 넣어야 결과가 바뀌는지 첫 화면에서 안 보인다.

### 양도·배당세 (/tax)
1. 결과 카드(흰색)의 큰 숫자 '1,045만'과 그 밑 '세후 3,955만 남아요 · 실효 21%'가 다른 질문(낼 세금 vs 남는 돈)에 답한다 — 숫자 1 원칙 깨짐.
2. 아래 3칸(양도차익·과세표준·실효세율 21%)이 위 문장의 '실효 21%'를 다시 말한다.
3. 결과 카드가 입력보다 위에 있는데, 바로 밑 입력 카드에 또 주황 버튼 '해외 양도세 반영'이 있다 — 입력하는 대로 바뀌는 화면에서 무엇을 '반영'하는지 모름.
4. 다른 계산기와 달리 여기는 결과가 흰 카드, 건보료는 다크 카드 — 형제 화면끼리 결과 그릇이 다르다.
5. 경고 박스가 버튼 바로 밑에 붙어 버튼 영역이 세 덩어리(버튼·경고·다음 카드)로 보인다.

### 파이어 유형 테스트 (/firetype)
1. 화면이 다크카드 하나뿐이고 아래 70%가 빈 회색이다. 무엇을 묻는 테스트인지(예: 첫 질문·결과 예시)가 안 보인다.
2. 제목 '나는 어떤 파이어족일까?'가 가운데 정렬 — 다른 화면은 전부 왼쪽 정렬.
3. '12문항·1분' 주황 배지 + 주황 단어 + 주황 버튼 = 주황 3곳(주황은 행동·핵심 숫자 1곳 규칙).
4. 바닥 회색 '투자 권유가 아니에요'가 버튼 바로 밑에 붙어 버튼 설명처럼 읽힌다.
5. 1440px에서도 같은 카드가 가운데 작게 떠 있다(아래 데스크톱 공통).

### 랭킹 (/ranking)
1. 첫 화면 위 절반이 빈 상태(아이콘+'계산하면 내 등수가 나와요'+회색 버튼)다. 처음 온 사람에게 가장 큰 자리가 '아직 없음'이다.
2. '계산하기'가 회색 보조 버튼 — 이 화면의 행동은 이것 하나인데 주황이 아니다.
3. 목록의 이름이 '상냥한 코알라48' 같은 자동 별명이고 전부 '20대' — 표본이 진짜인지 판단할 단서(전체 몇 명, 기준일)가 없다.
4. 아래 탭바 위로 '끈기를 가지...' 글이 비쳐 겹친다(탭바 반투명) — 캡처 하단.
5. 탭바(결과·바꿔보기·랭킹·전체)가 다른 도구 화면엔 없다. 같은 사이트 안에서 길 찾기 틀이 화면마다 다르다.

### 가이드 목록 (/guide/)
1. **파이어맵 디자인 시스템을 하나도 안 쓴다.** 흰 바탕, 브라우저 기본 글머리 점, 밑줄 친 주황 링크 — 다른 화면과 다른 사이트처럼 보인다.
2. 글 목록이 제목만 길게 이어진 링크 더미다(카드·날짜·분류·숫자 없음). 375px 첫 화면에 링크 7개가 밑줄로 빽빽하다.
3. 소개 문단 6줄이 목록보다 먼저 온다. 사람은 훑는데 첫 화면 절반이 문단이다.
4. 상단 '← 파이어맵 계산기'가 작은 밑줄 링크 — TopBar 부품을 안 쓴다.
5. 링크 줄이 두 줄로 꺾일 때 끝 글자가 한 단어로 남는다('되는 시점', '내는 순서').
