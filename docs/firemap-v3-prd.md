# FireMap v3 PRD (제품 요구 정의서)

> 단일 진실원천. 2026-06 리서치(시장·경쟁·UX·수익화·법률) + 기존 v3 plan 통합본.
> 세무·연금 수치는 시행연도 명기 + 출시 전 검증 필수(아래 부록 A).

## 0. 한 줄 정의 & 포지셔닝
- 제품: 한국형 은퇴 의사결정 웹앱 — "퇴사 가능 나이 계산기".
- 메인 카피: "내 진짜 사표 쓰는 날짜 알려주는 퇴사 나이 계산기".
- 키워드 포지셔닝: 전면 노출은 "퇴사 가능 나이 계산기"(대중 유입). "FIRE/파이어족"은 내부 등급·심화 탭에 부차 배치(브랜딩 깊이).

## 1. 문제 & 기회
- 소득 크레바스(주된 일자리 은퇴 50대 초 vs 연금 개시 전 공백)와 노후 불안.
- 기존 금융사·공공 계산기는 단순 소진율만 계산하고 한국 제도(건보료 피부양자, 해외주식 양도세, 배당 금융소득종합과세, 국민연금 조기수령)를 통합하지 못함 → 빈틈.

## 2. 타깃 페르소나 (우선순위)
1순위: **3040 미국주식(S&P500·고배당 ETF) 장기투자 직장인** — 고관여·구매력·바이럴 허브.
- 30대 사표 카운트다운형 / 40대 반퇴 시뮬레이터 / 배당 건보료 마지노선 관리자 / 미국ETF 분할매도 은퇴자 / 부동산 다운사이징 설계자 / 동남아 저물가 이민자 / 커뮤니티 인증 공유자.

## 3. 차별화 (해자)
- **What-If Compare 모드**: "생활비 30만↓ / 1년 더 근무 / 동남아 3개월"이 은퇴일을 몇 년 당기는지 오버레이 비교.
- **한국 사회보장·세제 실시간 융합**: 건보료·양도세·배당세·국민연금을 결과에 직접 반영.

## 4. 범위 — 가치순 단계 (우선순위 매트릭스 요약)
- Phase 1 (MVP): 현재/퇴사나이·금융자산·월저축·생활비 입력 → 자산수명 꺾은선, 수익률 프리셋, 1년더/저축증액 비교, Base64 조건 공유.
- Phase 2 (V2, 해자 핵심): 국민연금 조기수령 감액, 해외주식 양도세 22%, **건보료 피부양자 자동 판정**, 해외체류 건보료 정지, 도시 생활비 프리셋.
- Phase 3 (V3): FIRE 진단 점수·등급, 부업/생활비절감, 성적표 이미지, 부동산/대출.
- Phase 4 (고급): 환율 변동, 자녀 교육비 한시지출, Monte Carlo.
- 제외: 마이데이터 실시간 연동, 실시간 투자상담 채팅(법적 리스크).

## 5. 핵심 모듈 스펙 — 부록 A의 규칙을 엔진에 반영.

## 6. UX 원칙 (모바일 Safari 우선)
- 1화면 1질문 + 진행바, 좌우 슬라이드 전환.
- 숫자 입력: inputmode 숫자, 단위 칩(+500만/+1,000만/+1억) 가로 스크롤, 슬라이더+스텝퍼 병설.
- 하단 도크: safe-area-inset-bottom + visualViewport로 키보드 위 부착.
- 결과 대표 수치 32px+ 볼드. 차트는 기준선/대안선 2개만, 탭 시 나이·세후자산 카드.
- 광고: 차트와 버튼 사이 분리 + 최하단 고정 슬롯(CLS 방지). 면책은 푸터 11px.

## 7. 수익화
- 애드센스 + 금융 제휴(ISA·IRP) + 프리미엄 PDF 진단 리포트(₩9,900).
- 무료 85세 고정 단순결과 / 유료 100세 정밀 궤적·절세 전략 락.
- 마일스톤: 10만→50만→100만→300만원(트래픽·전환 가정은 리서치 참조).

## 8. 법률 / 컴플라이언스
- 자본시장법 무등록 투자자문 회피: 개별 종목 추천·매수 버튼 전면 차단, "기계적 수식 시뮬레이션 도구" 프레이밍, 일반화 지수 프리셋만.
- 온보딩 1회 EULA/면책 동의, 결과 하단 면책 배너, 과장광고 카피 금지(수학적 인과 표현만).
- 익명·무로그인·무저장(개인정보보호법 부담 최소화). 공유 링크 Base64 난독화.
- 애드센스 승인용 은퇴백과 10편+(1,500자+).

## 9. 성공 지표
- 방문→입력 시작률, 입력→결과 도달률, 결과→공유(링크/이미지) 복사율, 모바일 이탈률, PDF 결제 전환율.

## 10. 아키텍처 결정
- 핵심 계산 100% 클라이언트(프라이버시 해자). 정적 Cloudflare Pages 배포.
- 백엔드는 Supabase로 한정(커뮤니티/피드백, 추후 PDF/결제). 마이데이터 미연동.
- IA는 screen manifest(선언적 설정) 기반 라우팅(firemap-v3-ia.md 참조).

## 부록 A. 세무·정책 준거 데이터 (검증 필요 / 시행연도 명기)
건강보험 피부양자 자격:
- 합산소득 2,000만원 이하 AND 재산세 과표 5.4억 이하 → 유지.
- 재산과표 5.4억 초과~9억 이하 → 합산소득 1,000만원 이하만 유지.
- 재산과표 9억 초과 → 소득 무관 즉시 박탈.
- 금융소득(이자+배당) 1,000만원 이하면 합산서 전액 제외, 1원이라도 초과 시 전액 합산.
- 사업자등록+소득 발생 또는 주택임대소득 발생 시 즉시 박탈.
- 공적연금은 합산, 사적연금(IRP·연금저축)·ISA 배당은 제외.
국민연금 조기노령연금: 수령비율 = 100% - (6% x 조기 연수). 최대 5년 = 70%, 평생 미복원.
해외주식 양도세: (연간 손익통산 - 250만원 공제) x 22%. 과표 3억 초과분 27.5%. 환차익 산입(주가손실+환율상승 시 과세 케이스 경고). 양도소득 100만원 초과 시 부양가족 기본공제 상실.

## 11. 핵심 리텐션 루프 — FIRE 등수/등급 (제품 중심 목표)
목표: "전체 사용자 중 내 FIRE 가능 등수"를 보여 재방문을 유도. Result 화면의 히어로.
- 즉시(통계 기준): 최신 연령대별 소득·순자산 분포(예: 통계청 가계금융복지조사)로 "또래 상위 X%" 백분위 산출. 출처·기준연도 명기.
- 라이브(사용자 기준): Supabase에 익명 점수만 적재(fire_score + age_band + created_at; 금융 입력값 미저장)해 "사용자 N명 중 K등" 산출.
- 재방문 후킹: 시간 경과/신규 유입으로 등수 변동 → "이번 주 N명이 당신을 추월" 류 변화 노출.
- 공유: 개인 신상 없는 "FIRE 자생력 등급 카드" 이미지(퍼센타일·등급). 페르소나 #7(커뮤니티 공유자) 직접 충족.
- 가드레일: 저장은 비식별 점수·연령대로 한정. 금액(자산·소득·부채) 원본은 절대 미저장(opt-in 없이는). 등수는 "참고용" 면책.

## 12. 차트 (UX)
- 증권앱 스타일: 영역 그라데이션 + 크로스헤어 툴팁 + 깔끔한 축. 현재/What-If 2시리즈 오버레이.
- 데이터는 나이별 자산 투영(OHLC 아님) → area/line. 라이브러리 후보: Lightweight Charts(증권앱 룩) / ApexCharts(React 통합 용이) / Recharts.

## 13. 데이터 출처 & API (정합성·신뢰)
- 출처 메타데이터: 수익률 프리셋·세제 규칙·환율·도시 물가·통계 분포 각 항목에 source + 기준일. UI에 "출처/기준일" 노출.
- 런타임: 정적 호스팅 유지를 위해 (a) 빌드타임 시드 JSON, 또는 (b) Cloudflare Pages Function/Supabase edge 프록시로 환율·지수수익률·도시물가 갱신(클라이언트 키노출·CORS 회피). 핵심 계산은 클라이언트.
- 개발 시 시드값은 공개 통계/금융데이터 MCP(FMP 등)로 확보 후 출처와 함께 커밋.

## 14. 투자 수익률 벤치마크 비교 (교육용 · 컴플라이언스 주의)
목적: 예적금보다 높은 수익 가정을 적용했을 때 FIRE 자산 형성·시점이 어떻게 달라지는지 보여 동기 부여.
- 표시: S&P500·나스닥100·SCHD(배당다우존스) 등의 역사적 연평균 수익률(출처·기간 명기)과 예적금 금리 비교, 프리셋 적용 시 자산 궤적/FIRE 시점 변화.
- 데이터: 지수 역사적 수익률·예적금 금리는 출처·기준일 메타데이터 포함. 시드는 통계/금융데이터(공개 API 또는 FMP 등 MCP)로 확보, 필요 시 갱신.
- 컴플라이언스(필수): 기계적·교육적 벤치마크 시뮬레이션만. 특정 종목/ETF 매수 추천·매수 버튼·시점 권유 전면 금지. "과거 수익률은 보장값 아님, 투자권유 아님" 면책 상시 노출. 일반화된 지수 프리셋만 제공.

## 15. 입력 UX (사용자 친화성)
- 필드 성격별 입력: 돈(자산·생활비·저축·연금·부업)은 직접 숫자 입력 주력 + 단위 칩(+100만/+1,000만/+1억) + 슬라이더 보조, **상한 클램프 제거**(슬라이더 최댓값보다 큰 금액 입력 가능). 나이·수익률%는 슬라이더+스텝퍼.
- "탭해서 입력" 힌트로 직접 입력 발견성 확보.
- Compare(조건 바꿔보기)에 핵심 레버 전부 노출: 현재 나이·퇴사 나이·현재 금융자산·월 저축·생활비·부업 소득·수익률·절감안. 모두 즉시 재계산.

## 16. 네비게이션 & 버튼
- 로고 = 어디서나 처음으로(홈) 이동. 모든 서브 화면 '이전' + 브라우저 뒤로가기(popstate) 지원.
- placeholder 버튼 제거(예: 의견 FAB 아이콘화). 1차/2차 버튼 위계 명확화.
- 결과 화면에서 막히지 않게 홈·수정 경로 확보.

## 17. 공유 후킹 & OG (바이럴) — 현재 기초 단계, 개선 필요
- 목표: 공유받은 사람이 앱에 들어오고 싶게. 등급/등수 기반 "FIRE 자생력 등급 카드" 이미지(신상 배제) + 후킹 카피.
- OG 이미지: 결과/등급 반영한 동적 또는 템플릿 OG, 카카오톡 공유 미리보기 최적화.
- 조건 링크(Base64) + 결과 요약 카피 + 커뮤니티용 문구.

## 18. 코어 계산 신뢰성 (감사 결과)
- 검증: 8개 독립 시나리오(인출·복리적립·인플레 지수화·생존점수·연금 공백기) 손계산 일치 — 수학 신뢰 가능.
- 모델 한계(버그 아님, 향후 보정): (1) 월 저축 인플레 미반영 (2) 신규 저축 첫해 전액 수익률 (3) 부동산은 표시만·은퇴자금 미반영 (4) 결정론적 수익률(변동성/순서위험 없음, Monte Carlo는 Phase4) (5) 세금·건보료 기본계산 미반영(고급 모듈에서) (6) 입력 0이면 즉시 고갈로 '망함' 표시 → 첫 화면 UX 보완 필요.
- 배포: firemap-v3 Cloudflare 프리뷰 라이브(https://firemap-v3.retire-age-kr.pages.dev). 프로덕션은 아직 main.
