# 1차 이해 시험 (2026-10-20, 새 Agent 3명 — 40세 회사원·50세 자영업자·60세 은퇴자, 제목·표지·본문 따로)
## 40세
- 제목: 금리 오르면 장기채 쪽만 크게 손해, 그 이유 / 할 일: 내 ETF가 장기채인지 확인
- 표지: 10년 만기 ETF -6%, 단기 +2% / 심각: '10년 -6%'가 10년 동안 6%로 읽힘
- 본문: 듀레이션 길수록 금리 오를 때 많이 빠지니 사기 전 확인 / 할 일: 내 ETF 듀레이션 찾아 1억 기준 흔들림에 대 봄
- 심각: '약 576원 적었습니다' 계산 근거 없음 · 보통: 통안채·바스켓·YTM·원천징수 풀이 없음, -9.2%와 -6% 섞임, 770만원 손해인지 이득인지, 4.6→4.2% 방향 헷갈림
- 알게 된 것: 만기(듀레이션)가 길면 금리 오를 때 크게 손해, 사기 전 듀레이션 확인 / 남은 궁금증: 있음(금리 오르면 왜 채권값이 내리는지, 금리 전망) / 권유로 읽힘: 아니오
## 50세
- 제목: 장기짜리만 많이 손해 / 표지: 10년짜리 6% 잃고 단기 2% 벌었다(보통: '10년 -6%' 순간 헷갈림)
- 본문: 만기 긴 채권 ETF일수록 가격 많이 빠짐, 듀레이션으로 가늠·운용사 페이지 / 할 일: 듀레이션 확인, 1억당 흔들림 계산, 사고팔 결정은 안 함
- 심각: 통안증권 설명 없음 · 4.6→4.2% 방향 바뀜 · 보통: 듀레이션 '년' 단위, 숫자 셋(10%·9.2%·6%), 바스켓·YTM, 576원, 770만원 방향, '분배금 재투자 안 함'
- 알게 된 것: 같은 금리 상승에도 만기 긴 채권 ETF가 훨씬 손해, 듀레이션으로 가늠 / 남은 궁금증: 있음(통안채 안전한지, 장기채 들고 있으면 회복되는지) / 권유: 아니오
## 60세
- 제목: 장기채 ETF만 크게 손해 / 표지: 만기 긴 건 6% 잃고 짧은 건 2% 벌었다
- 본문: 만기(듀레이션) 긴 채권 ETF일수록 값이 많이 빠지니 사기 전 듀레이션 확인
- 심각: 듀레이션이 만기와 다른 이유(10년짜리인데 7.7년) · 9.2%와 6%·595만원 차이(가격만 vs 분배금 포함) · 770만원을 잃는다고 읽힘 · 보통: 분배금·통안채·YTM·바스켓·원천징수, 금리 오르면 예금은 좋은데 왜 채권은 빠지나, 4.6→4.2%가 '살 때' 암시로 읽힐 여지
- 알게 된 것: 금리 오르면 만기 긴 채권 ETF는 많이 빠지고 짧은 건 괜찮으며 듀레이션이 그 정도를 가늠 / 남은 궁금증: 있음(원리, 듀레이션 뜻) / 권유: 아니오
