# C-1 받아쓰기 대조 (Chirp 3 HD, 2026-10-11 PD)
- 처음 80줄: 걸린 3 — 7:4 '11년째'를 lite 2개가 '1일년째'로, 7:5 '2년이'를 '인연이'로, 8:1 '12년째'를 셋 다 '1년째'로 들음.
- 7:5: 다시 받음(retake) → 통과.
- 8:1: 다시 받아도 '1년째'로 들림 → ep/C-1/say.json에 읽기 표기 ["12년째", "십이 년째"] (대본·화면 글자 그대로, 소리만) → 통과.
- 7:4: 다시 받음 뒤 숫자(9·11)는 셋 다 맞음. 남은 표시는 '밀림의심(0.63)' 하나 — lite가 '바닥났습니다'를 '받아놨습니다', '씨는'을 '신은'으로 들음.
  Chirp은 줄마다 따로 받아 자르기가 없으므로 문장 밀림은 생길 수 없다. 같은 파일을 gemini-3.7-flash로 받아쓰니 "배당 시는 9년째 매도 시는 11년째에 바닥났습니다."(씨/시 동음만 다름) → 소리 맞음으로 판정.
