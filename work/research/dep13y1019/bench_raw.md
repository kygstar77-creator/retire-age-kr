# 경쟁 글 메모

### 1. imhogun — 길게 묻을수록 손해본다? 1년 or 3년
- 제목 틀: 상식 뒤집는 질문 + "A or B" 비교 질문, 이모지(🏦) 앞머리.
- 첫 3줄: "오래 묶을수록 이자 더 준다"는 상식 인용 → 2026년 8월 5대 은행 1년이 2~3년보다 높은 '금리 역전'이라고 바로 사실 제시 → "왜·어떻게 예치할지 수치로 정리" 예고.
- 구성: ① 얼마나 역전됐나(은행연합회 공시, 6·12·24·36개월 금리 범위 목록) → ② NH농협 1년 3.00% vs 2년 2.50% 예시로 1,000만원 2년 고정 vs 1년씩 롤오버, 손익분기 금리 계산 → 관련 글 링크 → 면책.
- 사진: 3장(+대표 1), 캡션 없음, 종류 확인 안 함. 자리: 첫머리·소제목마다.
- 끝맺음: 안내(면책 + 은행연합회 포털에서 최신 금리 확인하라). 질문 없음.
- 우리 주제와 가장 가까움. 3년이 아니라 2년으로만 계산한 게 빈칸.

### 2. my_name_jin — 우체국 예금금리 얼마일까? 1년·3년 정기예금 금리와 우대조건 비교
- 제목 틀: 기관명 + "얼마일까?" 질문 + 키워드 나열(1년·3년·우대조건).
- 첫 3줄: 자기소개(지역·직업·인플루언서) → 기준금리 3.00%로 예금 관심 증가 → 오늘 정리할 범위 예고.
- 구성: 인용구로 제목 반복 → 현재 금리 → 6개월·1년·3년 기본금리 → "1년과 3년 차이 크지 않다"(우체국은 3년이 0.05%p 높음) → 1,000만원 세후 이자 → 우대조건 → 금리 오른 이유 → 1년 vs 3년 어느 쪽 → 안전성 → 정리.
- 사진: 10장, 캡션 없음, 종류 확인 안 함. 자리: 소제목마다 1장씩 끼움.
- 끝맺음: 요약 → "최종 금리 다시 확인하라" 안내 → 팬하기 부탁.
- 주의: 우체국은 3년이 1년보다 높다고 씀. 5대 은행 역전과 반대 사례라 '어디나 역전'이라 쓰면 틀린다.

### 3. hublessing100 — 정기예금 풍차돌리기 12개 계산해 보니.. 이자 두 배인 줄 알았는데
- 제목 틀: "~해 보니.." 직접 해본 체험 + 기대 뒤집기(말줄임).
- 첫 3줄: 풍차돌리기 뜻 한 줄 → 조회 일시(10월 6일 오후 8시)·출처(금감원 통합비교공시) 밝히고 직접 계산 → "이자는 두 배 가까이, 그런데 이유는 금리가 아니었다, 답은 끝에서".
- 구성: 쓴 금리 → 같은 1,200만원 세 가지 넣기 → 통장 12개 만기 시점 → 1년째 손에 쥔 돈 → 평균 잔액·기간 → 나의 생각 → '정답' 소제목(기간과 만기일 12번) → 상품명 → 공시 캡처 2장 → 출처·면책 → 이전 글 링크.
- 사진: 8장. 직접 만든 계산 그림 5장(캡션에 "직접 계산"), 만기 후 이율 그림 1장, 금감원 공시 캡처 2장(맨 끝). 소제목 아래 1장씩.
- 끝맺음: 사실(출처·조회 시각) + 안내(권유 아님). 질문 없음.
- 반응은 0이지만 구조가 우리 '검증된 정보글' 틀과 같음.

### 4. bhivv — 기준금리 3%인데 정기예금 지금 들까? 6개월·1년 가입 시기는?
- 제목 틀: 상황(기준금리 3%) + "지금 들까?" + 하위 질문.
- 첫 3줄: 목돈 넣을지 기다릴지 고민 시점 → 추가 인상 가능성 있지만 예금금리 오른다는 보장 없음 → 최고금리보다 "언제까지 묶을 수 있나"부터.
- 구성: 결론 먼저(무조건 기다릴 것도 묶을 것도 없음) → ①~⑦ 번호 소제목(왜 올렸나, 6개월·1년 무엇부터, 나눠 넣기, 실제 적용금리·중도해지 확인) → 요점정리(KDB 6개월·12개월 금리).
- 사진: 3장, 캡션형 설명(상황 그림·비교 그림·5,000만원 세후 이자 비교). 소제목 사이.
- 끝맺음: 사실 요약 + 확인할 것 안내.

### 5. popcorneconomy — 정기예금 금리 비교 1억원 굴리기, 만기 세금 전략 꿀팁
- 제목 틀: 키워드 + 금액(1억원) + "꿀팁".
- 첫 3줄: 기준금리 3.00% 인상 → 기존 통장 금리는 저절로 안 오름 → 같은 1억도 만기 설정·절세 통장에 따라 수령액 갈림.
- 구성: 인용구 소제목 5개(예금자보호 1억 분산 → 은행별 우대·한도 격차 → 장단기 역전 속 만기 선택 → 15.4% 절세 통장 → 만기 후 0.1% 관리).
- 사진: 5장, 상담 장면 같은 분위기 사진(캡션: "재무상담사와 중년 고객의 상담" 등). 인용구 소제목마다 1장. 표·캡처 없음.
- 끝맺음: 만기 방치 시 금리 떨어지는 사실 + 출처 한 줄.
- 주의: "1년이 3년보다 0.8%p 이상 높다"는 수치를 출처 없이 씀.

### 6. xonix229 — [가장 보통의 투자] 4% 정기예금, '6개월 vs 1년' 뭐가 유리할까?
- 제목 틀: [연재명] + 금리 + 'A vs B' + "뭐가 유리할까?".
- 첫 3줄: 결론 먼저(금리 전망과 자금 목적에 따라 다름) → 하락 예상이면 1년 고정 → 추가 인상 기대·단기 운용이면 6개월.
- 구성: 표(기간별 실수령 이자) → 1억 세후 계산 → 표(6개월 유리한 경우) → 표(1년 유리한 경우) → 인용구(금리 하락기 전략) → 표(가입 전 체크리스트) → 표+Q&A(FAQ).
- 사진: 2장(종류 확인 안 함) + 네이버 표 5개. 표가 주력.
- 끝맺음: FAQ(연 4%는 6개월에 2%라는 뜻, 중도해지 등). 질문으로 끝나지 않음.

## 6편 공통점 (위 메모에서 센 것)
- 제목 6편 중 5편이 물음표로 끝남. 비교형은 "A vs B"·"A or B".
- 첫머리 6편 중 4편이 결론이나 핵심 사실을 바로 앞에 둠.
- 6편 모두 세후 이자(15.4%)를 계산함. 3년을 실제 숫자로 끝까지 계산한 글은 0편(1번은 2년, 2번은 우체국 1년만).
- 끝맺음은 6편 모두 '최신 금리 확인/권유 아님' 안내. 독자에게 질문하는 끝맺음 0편.
- 공시 캡처를 넣은 글은 3번 하나.
