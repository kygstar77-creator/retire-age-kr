# 수익률 시나리오 MVP 메모

수익률은 FIRE 결과의 핵심 가정이다. 현재 계산 엔진에는 기본 연 8%, 물가 3%가 들어가 있지만 화면 노출은 부족하다.

## MVP 1차

- 결과 화면에 현재 계산 기준 표시: 연 수익률 8% · 물가 3%
- 조건 바꿔보기 화면에 수익률 조절 추가
- 직접입력은 이후 단계로 미룸

## MVP 2차

- 보수형
- S&P500형
- 나스닥100형
- 미국배당다우존스형
- 직접입력

각 시나리오는 자산수명 결과를 카드로 비교한다.

## 데이터 원칙

- 최신 통계가 확인된 수익률만 사용
- 2025~2026년 기준 자료가 없으면 앱에 확정값처럼 넣지 않음
- 소비자 화면에 작게 출처 표시
- 수익률은 보장 문구 금지

## 차트 반영

차트는 주식창처럼 친숙하게 보되, 목적은 수익률 자랑이 아니라 FIRE 경로 비교다.

- 현재 계획
- 생활비 절감안
- S&P500형
- 나스닥100형
- 배당다우존스형

1차는 너무 많은 선을 동시에 보여주지 않고, 카드 선택 또는 토글 방식으로 간다.
