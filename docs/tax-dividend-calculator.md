# 배당금·해외주식 세금 계산기 기능 범위

## 목적

FIRE 계산에서 배당소득세와 해외주식 양도소득세를 빠뜨리면 실제 사용 가능한 현금흐름이 과대평가될 수 있다. 따라서 분석 탭에 독립형 세금 계산기를 제공한다.

## 현재 구현 범위

- 연간 배당금 입력
- 배당 기본 세율 입력
- 금융소득 확인 기준 입력
- 초과분 추가 추정세율 입력
- 해외주식 연간 양도차익 입력
- 해외주식 기본공제 입력
- 해외주식 양도세율 입력
- 목표 월 세후 배당금 입력
- 예상 배당률 입력
- 배당 재투자 비율 입력

## 결과 표시

- 연 세후 배당금
- 월 세후 배당금
- 배당 세금 추정액
- 해외주식 양도세 추정액
- 해외주식 세후차익
- 목표 월 세후 배당금을 만들기 위한 필요 원금

## 설계 원칙

- 실제 신고 금액을 확정하지 않는다.
- 세율과 공제액은 기본값을 제공하되 사용자가 직접 수정할 수 있게 한다.
- 금융소득 종합과세는 확정 계산이 아니라 초과분 민감도 확인용으로 둔다.
- 계좌 종류, 외국납부세액공제, 손익통산, 환율, 수수료, 거주자 여부는 별도 안내 문구로 처리한다.
- 개인정보, 계좌번호, 증권사 연동 정보는 수집하지 않는다.

## 향후 연결 계획

1. 분석 탭에서 독립형 계산기로 먼저 제공한다.
2. 사용자가 원하면 배당 세후 현금흐름을 퇴사 후 추가소득으로 반영하는 버튼을 추가한다.
3. 해외주식 양도세는 매년 반복 비용이 아니라 매도 시점 이벤트로 별도 시나리오화한다.
4. 환율 API가 붙은 뒤 해외주식 양도차익 계산에도 환율 기준일을 표시한다.

## 금지 표현

- 실제 납부세액 확정
- 세금 최적화 보장
- 종합과세 회피 가능
- 신고하지 않아도 됨

## 권장 문구

> 이 계산기는 입력값에 따른 참고용 추정입니다. 실제 세금은 신고연도, 계좌 종류, 외국납부세액공제, 손익통산, 환율, 수수료, 종합소득세율에 따라 달라질 수 있습니다.
