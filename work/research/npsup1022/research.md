# 왜
- 오르는 이유: 2025.4.2 국민연금법 개정(부칙 제4조)이 2026~2033 해마다 0.5%p 올리도록 정함(S1·S2) — 법조문에 이유 문장은 없음
- 세금이 줄어드는 이유: 연금보험료는 낸 만큼 소득에서 빼 주기 때문(S4) → 더 낸 돈 × 내 세율만큼
- 건보 동결 이유: 보도상 추가 보험료 수입·재정 절감·가계 부담(S7, 2차) — 글에서는 정했다는 것까지만
- 659만원에서 멈추는 이유: 기준소득월액 상한(S9)

# 그래서
- 1월 명세서에서 국민연금 줄이 기준소득월액의 0.25%만큼 느는지 확인
- 연말정산 때 국민연금 보험료가 소득공제로 들어갔는지 확인
- 지역가입자는 두 배로 오르니 소득 신고액 확인
- 지금 실수령은 파이어맵 계산기(2026년 요율)에 넣고 국민연금 칸에 0.25% 더함

# 누구라면
1. 월 300만원 직장인(15% 구간): 1년 9만원 더 냄, 약 1만5천원 돌아옴, 실제 약 7만5천원
2. 월 500만원 직장인: 15만원 → 실제 약 12만5천원
3. 월 659만원 넘는 직장인(24% 구간): 약 19만8천원 → 약 14만6천원, 7월 상한 바뀜
4. 지역가입자 소득 200만원: 월 1만원(두 배)
5. 부양가족·카드 공제가 많아 세율 구간이 낮은 사람: 돌아오는 몫 줄어듦

# 함정
1. 보험료율 10%를 월급 공제율로 착각 — 직장인 몫은 5%
2. 더 내면 그만큼 더 받는다고 생각 — 식에 보험료율 없음(S3)
3. 기준소득월액 ≠ 통장 실수령
4. 659만원 넘는 사람은 내년 7월 상한 바뀌면 금액 달라짐
