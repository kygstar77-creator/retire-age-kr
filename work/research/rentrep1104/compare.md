# rentrep1104 경쟁 비교 (bench.md 6편)
- 경쟁이 잘하는 것: 1(bizplany)은 시행령 별표3 개정표를 보도자료에서 옮겨 칸별 금액과 개정 전 금액을 같이 보였고, 3은 확정일자 자동 부여 조건(계약서 첨부)을 짚음
- 우리가 따라갈 것: 1의 제목 틀(검색어 + 결과 물음)·글자 카드 표지, 3의 '변경 신고 30일' 함정
- 우리가 다르게 할 것: 월세 계약의 계약금액(보증금 + 월세×200)을 서울 아파트 9~10월 실거래 1만 5,597건에 넣어 59.8%가 한 칸 이상 올라간다는 숫자(경쟁 0편, 2는 200배를 예시 하나로만)
- 경쟁 1등(1)보다 나은 점: 내용 — 별표3 원문 PDF로 공동신고 거부 = 2년 초과 금액·절반 가감·늦은 기간 기산일까지 확인, 실거래로 직접 센 칸 분포 / 형식 — 4×5 표 대신 막대 두 줄
- 우리 지난 글보다 나아진 점: leasereg1102(임차권등기)는 기간 하나만 셌는데, 이번엔 법 조문 계산식을 실제 계약 1만 5천여 건에 적용
- 경쟁 1등이 나은 점: 개정 전 금액과 나란히 보여 '100만원 아님'을 바로잡음 → 다음 편에서 흔한 오해 하나를 숫자로 바로잡는 줄을 앞에 둠
