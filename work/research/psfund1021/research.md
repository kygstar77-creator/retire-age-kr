# 왜
- 보험 수익률이 낮은 이유: 백서 — 가입 초반 사업비 등 수수료로 적립금이 납입금보다 낮을 수 있고, 운용수익이 공시이율로 정해짐(p.6~7, 별첨 p.9)
- 펀드가 높았던 이유: 원문은 2025년 증시 상승 외에 상품별 이유를 따로 적지 않음 — '고른 펀드·ETF 값에 따라' 오르내린다는 구조만 씀
- 이전하면 세금이 없는 이유: 시행령 40조의4① — 다른 연금계좌로 이체는 인출로 보지 않음

# 그래서
- 보험사에 '지금 옮기면 얼마가 넘어가는지(해지공제액)'를 먼저 묻는다
- 옮길 증권사에서 연금저축계좌를 열고 '이전'으로 신청한다(해지 후 재가입 아님)
- 펀드로 옮기면 원금 보장·예금자보호가 없어지는 것을 알고 고른다

# 누구라면
1. 가입 7년 넘은 보험 가입자: 해지공제액 부담이 적어 이전 비교가 쉬움
2. 가입 7년 안 보험 가입자: 이전 때 해지공제액이 생길 수 있어 금액부터 확인
3. 원금 손실이 싫은 사람: 보험은 원금 보장·예금자보호(S5), 펀드는 아님
4. 급히 돈이 필요해 해지하려는 사람: 세액공제 받은 돈+수익에 16.5%

# 함정
1. 해지하고 새로 가입하면 이전이 아니라 중도해지 — 16.5%
2. 7년 안 보험은 이체 때도 해지공제액(S6)
3. 보험(납입보험료 대비 수익률·판매 후 경과기간)과 펀드(수정기준가 수익률·공시일에서 과거 기간)는 재는 방식이 다름(S1 별첨 p.9 각주) — 백서의 '직접 비교 한계'는 전년 수익률과의 비교(레드팀 지적으로 바로잡음)
4. 10년 연평균은 지난 숫자 — 앞으로 같다는 뜻 아님

# 한계
- 보험의 10년 수익률은 '판매 뒤 10년 지난 상품' 기준, 펀드/ETF는 '공시일에서 거슬러 10년' 기준이라 같은 기간이 아님(S1 별첨 p.9) — 본문에 적음
- 1,000만원 계산은 연평균이 해마다 그대로 쌓인다는 가정(실제 매년 수익률은 다름)
- 이전 때 넘어가는 금액이 '해지환급금 기준'이라는 공식 문구는 못 찾음 → '해지공제액이 생길 수 있다'(S6 문구)까지만 씀
- 생명·손해보험별 수익률, 보험→펀드 이전 건수는 원문에 없음
- 지방소득세는 지방세법 103조의13(소득세의 10%)로 16.5% — 세액공제 안 받은 납입금은 이 세금 대상이 아님(S3 연금외수령 대상은 공제받은 납입금·운용수익)
