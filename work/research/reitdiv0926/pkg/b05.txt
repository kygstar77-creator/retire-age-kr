**배당을 실제로 올리고 있나**

배당률이 높아도 금액이 몇 년째 그대로면 얘기가 다르죠.

최근 여섯 번 이력을 폈습니다.

| 종목 | 최근 6회 흐름 |
|---|---|
| W.P.캐리(WPC) | 0.89 → 0.90 → 0.91 → 0.92 → 0.93 → 0.94 |
| 사이먼 프로퍼티(SPG) | 2.10 → 2.15 → 2.20 → 2.20 → 2.25 → 2.25 |
| 비치 프로퍼티스(VICI) | 0.433 → 0.45 → 0.45 → 0.45 → 0.45 → 0.46 |
| NNN 리츠(NNN) | 0.58 → 0.60 → 0.60 → 0.60 → 0.60 → 0.62 |

W.P.캐리가 눈에 띕니다.

여섯 분기 연속으로 1센트씩 올렸어요.

분기마다 오르는 곳은 이 한 곳뿐이었습니다.

사이먼 프로퍼티는 두 분기에 한 번꼴로 올렸고요.

비치 프로퍼티스와 NNN 리츠는 1년에 한 번씩 올렸습니다.
