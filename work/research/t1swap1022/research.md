# 왜
- 2년으로 줄인 이유: 시행령·부칙 원문에 이유 문장 없음 → 글에 이유를 쓰지 않음(정부 개정 설명자료는 이번에 확인 안 함)
- 분양권이 3년 그대로인 이유: 156조의3은 2026.9.30 개정 대상이 아니었음(S4 개정 표시 2025.12.30) — 왜 빼었는지는 원문에 없음
- 판단 시점이 새 집 산 날인 이유: 조문이 '신규 주택의 취득일 현재'로 적음(S1)

# 그래서
- 새 집 잔금일(또는 먼저 한 등기 접수일)과 계약금 이체일을 확인하고 서류를 남긴다(S1·S3)
- 내 두 집이 그날 조정대상지역이었는지 국토교통부 공고로 확인
- 분양권이면 분양권 산 날부터 3년, 넘기면 완공 뒤 3년 안 이사·1년 거주 계획

# 누구라면
1. 서울 집 + 9월 서울 새 집 잔금(8/4 이후) → 2년
2. 서울 집 + 8월 1일 계약금 낸 서울 새 집 → 3년
3. 서울 집 + 조정대상지역 밖 새 집 → 3년
4. 서울 집 + 동탄 분양권 → 156조의3, 분양권 산 날부터 3년

# 함정
1. 계약일을 기준으로 착각 — 양도세는 새 집 취득일(잔금) 기준, 8/3 예외만 계약금
