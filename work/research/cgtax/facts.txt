양도소득세(주택) 사실표 — 2026-09-22 22시 회차
원문: law.go.kr DRF XML (law/itax.xml 소득세법 시행 2026.1.1 공포 2025.12.23, law/itax_dec.xml 소득세법 시행령 시행 2026.7.1 공포 2026.5.22)

[법 제89조①3호] 1세대 1주택(대통령령 요건 충족) 양도소득 비과세. 단 양도 당시 실지거래가액 합계 12억원 초과 고가주택은 제외.
[시행령 제154조①] 요건: 양도일 현재 국내 1주택, 보유기간 2년 이상. 취득 당시 조정대상지역 주택은 보유 2년 이상 + 보유기간 중 거주 2년 이상.
[법 제95조①] 양도소득금액 = 양도차익 − 장기보유 특별공제액
[법 제95조②] 장기보유특별공제: 보유 3년 이상 토지·건물. 표1 3년 6% ~ 매년 2%p ~ 15년 이상 30%(5년 10%, 10년 20%).
  1세대 1주택(대통령령)은 표2: 보유 3년 12%, 4년 16%, 5년 20% … 10년 이상 40% + 거주 2년(보유 3년 이상 한정) 8%, 3년 12%, 4년 16% … 10년 이상 40%.
[시행령 제159조의4] 표2 대상 1세대 1주택 = 양도일 현재 국내 1주택 + 보유기간 중 거주기간 2년 이상.
[법 제95조③ / 시행령 제160조①] 고가주택 양도차익 = 양도차익 × (양도가액 − 12억원) / 양도가액. 장기보유특별공제액도 같은 비율로 계산.
[법 제97조①] 필요경비 = 취득가액(실지거래가액) + 자본적지출액 + 양도비 등.
[법 제103조①] 양도소득 기본공제 연 250만원(미등기양도자산 제외).
[법 제104조①] 세율: 1호 제55조① 기본세율(분양권 60%) / 2호 보유 1년 이상 2년 미만 40%(주택·조합원입주권·분양권 60%) / 3호 1년 미만 50%(주택·입주권·분양권 70%). 둘 이상 해당하면 큰 세액.
[법 제55조①] 6% (1,400만 이하) / 84만+15% (5,000만 이하) / 624만+24% (8,800만 이하) / 1,536만+35% (1.5억 이하) / 3,706만+38% (3억 이하) / 9,406만+40% (5억 이하) / 1억7,406만+42% (10억 이하) / 3억8,406만+45% (10억 초과)
[법 제105조①1호] 예정신고: 양도일이 속하는 달의 말일부터 2개월 (토지거래허가구역 예외 있음)
[법 제110조①] 확정신고: 다음 연도 5월 1일~5월 31일

[계산값 — 필요경비는 취득가액만, 지방소득세 제외, 다주택 중과 제외, 그 해 다른 양도 없음]
 A. 1세대 1주택 7억 취득 → 15억 양도, 10년 보유·10년 거주: 양도차익 8억 × 3/15 = 1억6천만원, 장특공 80% 1억2,800만원 → 3,200만원 − 250만 = 과표 2,950만원 → 84만 + 1,550만×15% = 316만5천원
 B. 같은 집, 10년 보유·거주 2년: 공제 40%+8% = 48% → 1.6억×52% = 8,320만원 − 250만 = 8,070만원 → 624만 + 3,070만×24% = 1,360만8천원
 C. 1주택 비과세 아닌 경우(일반세율) 5억 취득 → 8억 양도, 5년 보유: 차익 3억, 표1 10% 3천만 → 2억7천만 − 250만 = 2억6,750만원 → 3,706만 + 1억1,750만×38% = 8,171만원
 D. 주택 차익 1억, 1년 미만: (1억 − 250만) × 70% = 6,825만원 / 1년 이상 2년 미만 60% = 5,850만원
 E. 1세대 1주택 12억 이하 양도(요건 충족) → 비과세 0원
확인 안 함(본문에 안 씀): 다주택 중과세율·유예, 개인지방소득세율 조문, 일시적 2주택 기간, 필요경비 세부(중개수수료 등 시행령), 가산세
