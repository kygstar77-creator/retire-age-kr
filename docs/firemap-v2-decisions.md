# 파이어맵 2.0 의사결정 기록

이 문서는 파이어맵 2.0 개발 중 합의한 UX, 기능, 문구, 운영 기준을 잊지 않기 위한 기준서입니다.

## 확정한 큰 방향

- 브랜드명: 파이어맵
- 포인트 컬러: 오렌지 + 차콜
- UX: 토스/삼쩜삼/뱅크샐러드식 단계형 화면 전환
- 초기 입력: 한 화면에 질문 하나씩
- 결과 이후: 조건 바꿔보기, 그래프, 도시 시나리오, 공유, 정책/문의
- 운영 브랜치 main은 바로 건드리지 않고 preview 브랜치에서 먼저 테스트

## 입력 UX

### 질문 5개

1. 현재 나이
2. 퇴사 희망 나이
3. 금융자산
4. 퇴사 전 월 저축액
5. 퇴사 후 월 생활비

### 입력 단위

- 나이: 1세 단위
- 금융자산: 100만 원 단위
- 월 저축액: 10만 원 단위
- 월 생활비: 10만 원 단위
- 해외 체류 개월: 1개월 단위, 결과 이후 조건 바꿔보기에서 확장

### 프리셋 버튼

- 나이: 프리셋 제거
- 금융자산: 1억 / 3억 / 5억 / 10억 유지
- 월 저축액: 50만 / 100만 / 200만 / 300만 유지
- 월 생활비: 250만 / 350만 / 500만 / 700만 유지

### 입력 카드 개선 사항

- 숫자는 박스 안에만 표시하고 아래 중복 표시 금지
- 직접 입력은 숫자 박스 탭 시 가능
- 초기화는 실수 방지를 위해 확인창 필요

## 결과 화면 문구

### 홈

내 돈으로 몇 살까지 버틸 수 있을까?
퇴사나이와 FIRE를 앞당기는 방법을 2분 만에 계산해보세요.

### 결과

{퇴사나이}세에 퇴사하면 {자산수명}까지 버틸 수 있어요.
현재 가정으로는 {안전퇴사나이}세 퇴사가 더 안전해 보여요.

### 개선 카드 순서

1. 월 생활비를 350만 원으로 낮추면
2. 퇴사 후 월 100만 원 벌면
3. 1년 더 근무하면
4. 퇴사 전 월 100만 원 더 모으면

주의: “월 100만 원 더 벌면”은 반드시 “퇴사 후”를 붙여 부업/파트타임/소액 현금흐름 의미가 명확해야 합니다.

## 조건 바꿔보기

- 결과 화면에서 조건 바꿔보기로 이동 가능
- 조건 바꿔보기 화면에는 반드시 결과로 돌아가기 버튼 필요
- 초기화 버튼만 있으면 사용자가 실수로 처음으로 돌아가 불편함
- 조정 항목: 퇴사 나이, 생활비, 월 저축액, 이후 해외 체류 개월 확장

## 그래프

현재 문제:

- 축 수치가 없으면 사용자가 어느 시기에 얼마인지 알기 어려움
- 그래프 선만 있으면 해석이 어려움

필수 개선:

- 가로축: 나이 표시
- 세로축: 자산 규모 표시
- 현재 계획과 개선안 범례 표시
- 마지막 자산값 요약 표시
- 다음 단계: 점을 누르면 해당 나이의 자산값을 보여주는 인터랙션 추가

## 도시 시나리오 / 큐레이션

목표:

- 단순 문구가 아니라 “사는 곳을 바꾸면 FIRE가 얼마나 가까워지는지” 보여주는 콘텐츠

MVP 포함:

- 국내: 전주 / 원주 / 강릉
- 해외: 치앙마이 / 다낭 / 쿠알라룸푸르
- 현재 생활비 대비 예상 절감액 표시
- 최신 공식 자료가 확인된 항목만 보여준다는 안내
- 실제 생활비, 의료비, 주거비, 환율, 비자 조건에 따라 달라질 수 있다는 고지

나중에 확장:

- 환율 API
- 도시별 생활비 데이터
- 건보료 조정 가능성 계산
- 1개월 단위 해외 체류 조절
- 3개월 이상 체류 배지

## 공유

기존 문제:

- 결과 문구를 복사해 카톡에 붙여넣으면 디자인된 카드가 나오지 않음
- 링크 미리보기 OG 이미지는 앱 기본 미리보기일 뿐 개인 결과 카드가 아님

MVP 개선:

- 결과 문구 복사
- 앱 기본 링크 복사
- 내 조건 링크 복사
- 이미지 카드 만들기/공유 버튼 추가

주의:

- 실제 결과 카드 이미지는 canvas 기반으로 생성
- iOS/Android에서 navigator.share 파일 공유 가능 여부 확인 필요
- 불가능하면 새 창으로 이미지 열고 길게 눌러 저장하도록 안내

## 정책 / 신뢰 / 문의

반드시 유지:

- 입력값은 서버로 전송하지 않고 이 브라우저에 저장됩니다.
- 본 서비스는 투자·세무·법률 자문이 아닌 참고용 계산입니다.
- 내 조건 링크를 공유하면 일부 입력값이 링크에 포함될 수 있습니다.
- 피드백·협업 문의: retireage.kr@gmail.com

## 광고 / AdSense

- 질문 중간에는 광고를 넣지 않음
- 광고는 결과 이후에만 자연스럽게 배치
- 사용자에게 광고 클릭을 유도하는 문구 금지
- 기존 ads.txt, AdSense publisher ID는 유지
