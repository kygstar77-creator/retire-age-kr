# 파이어맵 2.0 자산 그래프 방향

파이어맵의 그래프는 일반 계산기 그래프가 아니라 사용자가 이미 익숙한 주식 차트 문법을 빌려 만든 **FIRE 자산 수명 차트**로 발전시킵니다.

## 핵심 판단

사용자에게 가장 친근한 그래프 문법은 주식 차트입니다.

사람들은 이미 아래 화면에 익숙합니다.

- 토스증권
- 네이버증권
- 야후파이낸스
- 업비트/빗썸 차트
- ETF·연금 계좌 수익률 화면

따라서 파이어맵의 그래프는 `연도별 자산 그래프`라는 설명형 차트가 아니라, 사용자가 보자마자 이해하는 **내 미래 자산 차트**가 되어야 합니다.

## 주식 차트에서 빌릴 것

### 1. 선형 자산 흐름

- x축: 나이 또는 연도
- y축: 예상 금융자산
- 선: 현재 계획
- 보조선: 개선 시나리오

### 2. 현재값과 끝값 강조

주식 차트처럼 숫자를 크게 보여줍니다.

- 현재 금융자산
- 퇴사 시점 자산
- 자산 소진 예상 나이
- 85세 예상 잔액

### 3. 시점 마커

차트 위에 사용자가 의미를 이해할 수 있는 지점을 표시합니다.

- 오늘
- 퇴사 예정
- 자산 정점
- 자산 소진
- 국민연금 시작
- 해외 3개월 체류 적용

### 4. 기간 전환

주식 앱처럼 기간을 바꾸는 UI를 고려합니다.

- 10년
- 20년
- 퇴사 후
- 85세까지
- 전체

단, MVP에서는 너무 복잡하게 만들지 않고 `전체` 중심으로 시작합니다.

### 5. 손가락으로 찍어보는 값

다음 고도화에서 차트 특정 지점을 누르면 해당 시점 값을 보여줍니다.

예시:

- 47세: 1.8억
- 52세: 0원 예상
- 생활비 절감안: 56세까지 유지

## 그대로 따라 하면 안 되는 것

주식 차트의 모든 기능을 복사하면 안 됩니다.

하지 말 것:

- 캔들 차트
- 거래량
- 호가창
- 과도한 보조지표
- RSI/MACD 같은 투자 지표
- 너무 많은 색상
- 전문 투자자용 UI

파이어맵은 투자 앱이 아니라 FIRE 의사결정 앱입니다.

## 파이어맵식 재해석

주식 차트가 묻는 질문:

> 이 주식은 얼마나 올랐나?

파이어맵 차트가 물어야 하는 질문:

> 내 돈은 몇 살까지 버티나?
> 무엇을 바꾸면 더 오래 버티나?

따라서 차트의 목적은 수익률 자랑이 아니라 행동 제안입니다.

## 차트 카드 최종 구조

### 상단

- 제목: 내 미래 자산 흐름
- 보조 문구: 나이별 예상 자산과 개선 시나리오를 비교해요.

### 핵심 숫자

- 현재 계획: 45세까지
- 생활비 절감안: 49세까지
- 차이: +4년

### 차트

- 현재 계획: 회색 선
- 개선안: 오렌지 선
- 퇴사 시점: 점/라벨
- 소진 시점: 점/라벨

### 하단 해석

- 생활비를 낮추면 자산 소진 시점이 4년 늦춰져요.

## 카피 방향

개발자 문구 금지:

- 다음 단계에서 점을 눌러 해당 나이의 자산을 보는 기능을 추가할 수 있어요.

사용자 문구:

- 선을 따라가면 내 자산이 언제 줄어드는지 볼 수 있어요.
- 생활비를 낮추면 자산 소진 시점이 얼마나 늦춰지는지 보여줘요.
- 회색은 현재 계획, 주황색은 개선 시나리오예요.

## MVP 적용 범위

1차 적용:

- 제목 변경
- 범례 추가
- 현재 계획/개선안 해석 문구 추가
- 마지막 자산보다 자산 소진 나이를 더 강조

2차 적용:

- 터치 시 해당 나이 자산 표시
- 퇴사 시점/국민연금 시점 마커
- 기간 전환 버튼

3차 적용:

- 여러 개선안을 주식 종목 비교처럼 토글
- 내 조건 저장 후 시나리오별 차트 비교
- 가입자 평균과 내 시나리오 비교

## PM 기준

차트는 예뻐야 하지만, 예쁜 선보다 더 중요한 것은 질문에 답하는 것입니다.

최종 기준:

- 사용자가 차트를 보고 3초 안에 현재 계획과 개선안의 차이를 이해하는가?
- 사용자가 “생활비를 낮춰봐야겠다”, “1년 더 일하면 얼마나 달라지지?”라고 행동하게 되는가?
- 주식 앱처럼 익숙하지만, FIRE 앱답게 해석이 붙어 있는가?
