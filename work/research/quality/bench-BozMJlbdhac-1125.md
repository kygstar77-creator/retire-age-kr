# 사장님 공유 영상 분석 (11/25) — 이웃집사장 「"구글이 공식 인정한 유튜브 1위"…30억씩 버는 40대 아빠」

- 실측: 11/24 16시 공개 → 하루 만에 조회 44,814·댓글 584 (채널 구독 29.3만, 평균 영상당 약 2.5만 → 첫날에 채널 평균의 1.8배)
- 길이 22분. 주제는 부업·유튜브 수익 → 우리 범위(배당·지수·부동산) 밖. 형식만 본다.

## 가져올 것 (우리 범위 안에서)
1. 첫 40초 = 영상 속 가장 센 말 몰아 보여주기, 인사는 0:40에 처음 나옴 → C-37(첫 문장 인사 금지)과 같은 방향, 근거 하나 추가.
2. 실제 사람이 실제 장소를 돌아다니는 하루 따라가기(행사장→회사→사무실). 썸네일도 실제 얼굴+증거 소품(실버·골드 버튼)+두 줄 큰 글씨+따옴표 한 줄.
   → 우리 그래픽 썸네일엔 없는 '진짜 사람·진짜 장소'. 현장 촬영 건(사장님 결정 대기)의 사례로 붙여 둔다.
3. 제목 = 따옴표 인용 + 권위 + 인물(40대 아빠) + 숫자 → C-38(소문·조건으로 시작)의 인용형 변형.

## 가져오지 않을 것
- 댓글 남기면 자료·강의 준다(댓글 584개의 큰 몫) → 우리 규칙상 보상형 댓글 유도 금지.
- 검증 안 된 수익 주장(썸네일 '하루 순수익 7천만원' ↔ 본문 '연 30억'·'하루 촬영 8천만원' 서로 안 맞음).
- 채널 200개 AI 대량 운영 → 유튜브 반복·대량 생산 콘텐츠 수익화 제외 정책 위험. 우리는 한 채널에 한 편씩 잘 만든다.
